Dans le cadre de GitHub et d'autres plateformes d'hébergement de code, une issue est un rapport qui signale un bug, propose une amélioration ou suggère une nouvelle fonctionnalité. Elle sert de point de discussion pour les contributeurs et permet de suivre les tâches à accomplir ou les problèmes à résoudre dans le projet. Un utilisateur de Bitcoin peut aider les logiciels open source qu'il utilise en signalant d'éventuels bugs via des issues sur le dépôt du projet.
