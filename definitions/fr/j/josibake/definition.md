Développeur de Bitcoin Core qui signe *josibake* (OpenSats le nomme Josie Baker), premier auteur de BIP-0352, qui définit les *silent payments*.

Il contribue à Bitcoin Core depuis juin 2021, d'abord sur les tests, les outils de vérification du code et les RPC, puis sur le portefeuille et la sélection des pièces. Le 28 mars 2022, Ruben Somsen présente sur la liste bitcoin-dev les *silent payments*, des adresses statiques dont les paiements ne sont pas liés entre eux dans la blockchain. Le 11 octobre 2022, le développeur woltx y annonce la version 4 de son implémentation pour Bitcoin Core, qui ajoute la prise en charge du *coinjoin*. Le 9 mars 2023, le numéro BIP-0352 est attribué, avec Ruben Somsen et Sebastian Falbesoner comme coauteurs, et le texte est fusionné dans le dépôt des BIP le 8 mai 2024. Il est aussi l'un des trois auteurs de BIP-0375 (envoi de *silent payments* avec des PSBT, numéro attribué le 8 janvier 2025, au statut *Draft*).

Le 16 août 2023, OpenSats annonce lui accorder une bourse de long terme pour revoir du code de Bitcoin Core et poursuivre ce travail, notamment l'adoption par les portefeuilles hors de Bitcoin Core. Le 23 septembre 2026, la fusion de son module de calcul de BIP-0352 dans Bitcoin Core (sans le portefeuille) marque une première étape de l'intégration des *silent payments* au logiciel.
