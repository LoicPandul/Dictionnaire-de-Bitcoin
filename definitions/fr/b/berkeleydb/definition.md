Système de gestion de base de données intégrable avec une architecture de stockage clé-valeur. Il a été utilisé dans les premières versions de Bitcoin pour stocker les index de blocs et de transactions ainsi que le portefeuille. LevelDB l'a remplacé pour les index à partir de Bitcoin Core 0.8.0, en 2013, mais BerkeleyDB est resté le format des portefeuilles *legacy* jusqu'à Bitcoin Core 30.0, qui ne peut plus les créer ni les charger (ils se migrent vers le format à descripteurs).
