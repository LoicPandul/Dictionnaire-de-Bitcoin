Spécification qui établit le registre centralisé des *feature bits* utilisés dans le Lightning Network pour signaler les fonctionnalités supportées par chaque nœud. Les fonctionnalités sont annoncées par des *flags* dans les messages `init`, `node_announcement` et `channel_announcement`, ainsi que, selon la fonctionnalité, dans les invoices BOLT-11 et dans le champ `allowed_features` des chemins aveuglés. Chaque fonctionnalité utilise une paire de bits : le bit pair indique un support obligatoire, le bit impair indique un support optionnel.
