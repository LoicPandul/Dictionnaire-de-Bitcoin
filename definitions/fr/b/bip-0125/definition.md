Définit le concept de *Replace-by-Fee* (RBF), permettant à l'émetteur de remplacer une transaction non confirmée par une autre version qui inclut des frais de transaction plus élevés. Le BIP-0125 offre un cadre pour le signalement de RBF dans une transaction et pour son acceptation par les nœuds du réseau. Depuis Bitcoin Core 28.0, l'option `mempoolfullrbf=1` est activée par défaut : un nœud accepte alors le remplacement d'une transaction même si elle ne signalait pas sa remplaçabilité.
