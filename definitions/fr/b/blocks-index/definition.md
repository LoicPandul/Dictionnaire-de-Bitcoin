Structure de données LevelDB dans Bitcoin Core qui catalogue des métadonnées sur tous les blocs. Chaque entrée dans cet index renseigne des détails tels que l'identifiant du bloc, sa hauteur dans la blockchain, l'emplacement du bloc dans les fichiers `blk*.dat`, et d'autres métadonnées. Cette indexation permet de trouver rapidement un bloc stocké sur le disque.
