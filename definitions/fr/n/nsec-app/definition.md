Gestionnaire de clés Nostr en application web, qui garde la clé privée (`nsec`) de l'utilisateur et la met à disposition des autres applications par NIP-46, sans la leur remettre. nsec.app est un signataire distant, un *bunker* : une application cliente lui envoie par les relais une demande de signature ou de chiffrement, et le navigateur de l'utilisateur répond. Il est développé par l'équipe de Nostr.Band, autour d'Artur Brugeman, en TypeScript. Son dépôt, `nostrband/noauth`, ne porte pas de licence unique : le client est sous licence MIT, plusieurs paquets du serveur sous licence ISC.

Le signataire tourne dans un *service worker* du navigateur, ce qui lui permet de répondre même quand l'onglet est fermé. S'il est endormi, un serveur compagnon, `noauthd`, envoie une notification *push* qui le réveille. Pour connecter une application, nsec.app génère une URL `bunker://` à coller dans le client, ou accepte une URL `nostrconnect://`. Alice peut aussi s'inscrire directement : l'application lui attribue un nom NIP-05 de la forme `alice@nsec.app`, avec lequel elle se connecte aux clients Nostr, et elle règle les permissions de chaque application connectée. La clé reste chez l'utilisateur, et une copie chiffrée par un mot de passe peut être déposée sur le serveur de nsec.app pour la retrouver sur un autre appareil. Le README reconnaît toutefois que le réveil du signataire entre appareils est peu fiable, surtout sur un téléphone verrouillé. Depuis le printemps 2025, la clé peut aussi être confiée, en option expérimentale, à un signataire exécuté dans une *AWS Nitro Enclave*.

Le dépôt est créé le 1er décembre 2023, et l'article de No Bullshit Bitcoin du 14 février 2024 présente nsec.app, alors en bêta, comme un *nsecbunker* dans le navigateur. La bibliothèque `nostr-login`, du même groupe, permet à une application qui utilise NIP-07 de se connecter à un bunker NIP-46 avec peu de code. Artur Brugeman est l'auteur de NIP-50, qui définit la recherche sur les relais (17 janvier 2023) ; NIP-46 a été proposé par Marco Argentieri (PR fusionnée le 20 février 2023), et Nostr.Band l'a révisé en novembre 2024. Sur Android, AMBER remplit le même rôle de bunker avec une application native.

Au 26 octobre 2026, `use.nsec.app` répond toujours, mais le dernier commit du dépôt date du 26 mai 2025.
