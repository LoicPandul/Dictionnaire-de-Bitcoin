Bibliothèque TypeScript qui rassemble le code commun dont une application Nostr a besoin : connexion aux relais, abonnements, création et validation des événements, signature. NDK, pour *Nostr Development Kit*, est écrit par Pablo Fernandez, qui signe pablof7z, et publié sous licence MIT. C'est un outil pour les développeurs de CLIENT NOSTR, pas une application : un client qui l'utilise lui confie la gestion des relais et ne garde que son interface.

Le cœur, le paquet `@nostr-dev-kit/ndk`, accepte plusieurs signataires : une clé privée, une extension de navigateur (NIP-07) ou un signataire distant (NIP-46). Autour de lui, le monorepo publie des paquets séparés que le développeur choisit un à un : liaisons pour Svelte 5, React et React Native, sessions multi-comptes, messages privés NIP-17, filtrage par *web of trust*, synchronisation NIP-77, client Blossom, et plusieurs caches (mémoire, IndexedDB, SQLite, Redis, relais Nostr).

NDK intègre le modèle *outbox*, fondé sur NIP-65, que Mike Dilger a écrit, l'auteur de CLIENT GOSSIP. Pour lire les notes de Bob, un client construit avec NDK n'interroge pas une liste fixe de relais : la bibliothèque récupère la liste de relais NIP-65 de Bob (événement de kind `10002`) et choisit les relais d'après elle. Dans le code d'avril 2026, ce mode est actif sauf si le développeur le désactive.

Le lien de NDK avec Bitcoin passe par les paiements. La bibliothèque fournit des utilitaires pour les zaps (NIP-57) et pour les *nutzaps* (NIP-61), et un paquet de portefeuille qui gère Cashu, *Nostr Wallet Connect* et WebLN. Pablo Fernandez est l'auteur de NIP-60 (portefeuilles Cashu stockés sur des relais) et de NIP-61, ajoutés au dépôt des NIP le 25 octobre 2024, ainsi que de NIP-89 (applications recommandées), ajouté le 7 juin 2023.

Le premier commit de NDK date du 16 mars 2023. OpenSats le finance dès sa première vague de subventions Nostr, en juillet 2023, puis accorde à son auteur un soutien de long terme le 9 avril 2024. La version 1.0, annoncée le 7 septembre 2023, apporte le modèle *outbox*, alors désactivé par défaut. La version 3.0 sort le 10 février 2026, et la 3.0.3, publiée le 23 février 2026, est la plus récente sur npm au 25 octobre 2026. Le dépôt n'est pas archivé, son dernier commit connu date d'avril 2026.
