Signale un script invalide, ce qui rend l'output qui le contient non dépensable de manière prouvée. Bitcoin Core n'ajoute donc jamais cet output à son UTXO set. `OP_RETURN` est souvent utilisé pour inscrire des données arbitraires dans la blockchain. Par défaut, la règle de relais `datacarrier` de Bitcoin Core limitait ces données à 80 octets ; depuis Bitcoin Core 30.0, la limite par défaut de `-datacarriersize` est relevée à 100 000 octets virtuels.
