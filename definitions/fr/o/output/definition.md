Dans le contexte de Bitcoin, un output est la partie d'une transaction qui distribue des fonds : il stipule une certaine quantité de bitcoins, souvent attribuée à une adresse spécifique, ainsi que les conditions sous lesquelles ces fonds pourront être dépensés ultérieurement. Une transaction prend des outputs de transactions précédentes comme « inputs » (entrées) et crée de nouveaux outputs, ses « sorties ».

Tant qu'un output n'a pas été dépensé, il forme un _Unspent Transaction Output_ (UTXO). Le rôle de la transaction Bitcoin est donc de consommer des UTXOs en entrées, et de créer de nouveaux outputs en sorties. La différence entre les deux correspond aux frais de transaction qui peuvent être récupérés par le mineur gagnant du bloc. Un output reste un output une fois dépensé : seul le terme UTXO désigne ceux qui ne le sont pas encore. Les outputs d'une transaction sont donc de futurs UTXOs, qui seront à leur tour utilisés comme inputs dans des transactions futures.

D'un point de vue plus large, en informatique, le terme « output » désigne généralement les données en résultat d'une fonction, d'un algorithme, ou d'un système. Par exemple, lorsque l'on passe une donnée dans une fonction de hachage cryptographique, cette information est nommée « input », et le résultat est nommé « output ».
