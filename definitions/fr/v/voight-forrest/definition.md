Développeur de logiciels, créateur de P2Pool, un pool de minage décentralisé. Sous l'identifiant forrestv, il annonce P2Pool le 17 juin 2011 sur le forum Bitcointalk. Le Bitcoin Wiki le présente comme l'auteur du logiciel ; le dépôt de code montre qu'il l'a commencé dès le 15 mai 2011. Le wiki situe à la mi-juillet 2011 les tests sur le réseau principal ; ils suivent une réécriture complète du logiciel, une première version tournant déjà sur le réseau principal fin juin.

L'idée est de se passer de l'opérateur central des pools de minage classiques. Selon l'annonce, P2Pool fonctionne grâce à un réseau pair-à-pair de nœuds de mineurs. La version du 17 juin 2011 gardait toutefois une petite part centralisée, versée à son auteur ; la version entièrement décentralisée suit à partir de juillet 2011. D'après le Bitcoin Wiki, 0,5 % de la récompense revient au nœud qui trouve le bloc et les 99,5 % restants sont répartis selon le travail récent ; le logiciel réserve en outre par défaut 1 % du travail de chaque mineur à une adresse de don pour son développement (option `--give-author`).

Le message d'annonce a été modifié pour la dernière fois le 26 août 2017, pour y reporter la version 17.0 du logiciel. Le nom de Forrest Voight reste attaché à P2Pool.
