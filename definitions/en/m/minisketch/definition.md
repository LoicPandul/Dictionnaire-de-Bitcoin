Set reconciliation library developed mainly by Pieter Wuille (sipa). Minisketch implements an algorithm that lets two peers on a peer-to-peer network efficiently determine which elements one has that the other lacks, without each having to send the complete list of its elements.

The principle relies on sketches: each peer computes a compact representation of its set of elements, whose size depends on the number of expected differences rather than the total size of the sets. By exchanging these sketches, the two peers can identify the missing elements on each side and transmit only those. This mechanism considerably reduces the bandwidth consumed by gossip protocols.

Minisketch is the fundamental technical building block of Erlay, a proposal to improve transaction relay on the Bitcoin network. Currently, each node announces every transaction to all of its peers, which creates significant redundancy. With Erlay, nodes would announce transactions to only a small number of peers, then use reconciliation through Minisketch to synchronize their mempools with the others. This approach could reduce the bandwidth used for transaction announcements by about 84%, and overall bandwidth consumption by about 40%.
