In general computing, data that provides information about other data. Metadata describes the characteristics, content, quality, format, and structure of the data it accompanies. A distinction is thus made between the payload, which is the core of the information, and the metadata. For example, for a document, metadata can include the author, the creation date, the file size, and associated keywords. On Bitcoin, metadata appears in many elements: it is used in receiving addresses, extended keys, blocks...
