In the Bitcoin Core project, the most widely used node implementation on the Bitcoin network, maintainers are the individuals in charge of managing the project. They bear responsibility for the implementation. They handle moderation on the Bitcoin Core GitHub repository and set the schedule for publishing new releases. Above all, they are in charge of merging the pull requests (PRs) proposed by contributors.

In other words, when a proposed code change has passed the various stages of review, these maintainers take on the major responsibility of merging the new code into the Bitcoin Core software. Before merging, maintainers check that the code respects the fundamental principles of the project and meets the minimum standards required for inclusion, and they also judge the general consensus among contributors about the change. As of this writing (March 2026), Bitcoin Core has five maintainers: Hennadii Stepanov, Michael Ford, Ava Chow, Ryan Ofsky, and Sedited.
