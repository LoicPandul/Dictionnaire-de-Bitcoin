Very permissive free software license that allows users to copy, modify, merge, publish, distribute, sublicense, and sell the software. It requires only that the original license and the copyright notices be kept in all copies or substantial distributions of the software. Unlike the GPL, the MIT license does not require adaptations or derivative versions of the software to be distributed under the same license. This flexibility makes the MIT X11 license a popular choice for many open source projects, including in the Bitcoin ecosystem. Satoshi Nakamoto chose this license for the first version of Bitcoin, released in 2009, and it is still used by the Bitcoin Core project today.
