HTTP 402 reverse proxy developed by Lightning Labs, designed to allow paid access to web services over the Lightning Network. Concretely, Aperture sits in front of a web server or an API and requires a Lightning micropayment before granting access to the requested resource.

Aperture relies on the L402 protocol (Lightning HTTP 402), which combines the HTTP 402 status code ("Payment Required"), macaroons, and the Lightning Network to create a standard for authentication and payment on the web. When a client sends a request to a protected resource, Aperture responds with a 402 code along with a macaroon and a Lightning invoice. Once the payment is made, the client obtains a preimage that, combined with the macaroon, forms a valid L402 token. This token then serves as both authentication and proof of payment for subsequent requests.

Aperture supports proxying gRPC (HTTP/2) and REST (HTTP/1 and HTTP/2) requests. It also includes a rate limiting system per token or per IP address, based on a token bucket algorithm. Used in production by Lightning Loop, among others, Aperture illustrates a vision of the web where micropayments replace traditional subscription or advertising models to monetize APIs and online services.
