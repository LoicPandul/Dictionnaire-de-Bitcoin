Signing protocol that prevents a compromised hardware wallet from leaking the user's private key through the signatures it produces. In the ECDSA or Schnorr signature scheme, each signature requires a random nonce. A malicious device can manipulate this nonce to covertly encode information about the private key in it, an attack known as a "covert channel" attack. The Dark Skippy attack notably showed that it is possible to extract an entire HD seed from just two signatures.

The anti-exfiltration protocol (also called "anti-klepto") relies on an exchange of nonce contributions between the host (the wallet software) and the hardware wallet. The host first supplies a random value to the hardware signer, which must include it in its nonce computation. The final nonce therefore results from the combination of both contributions, which prevents either party from controlling it alone. Thanks to a cryptographic commitment, the host can verify that its contribution was indeed taken into account in the signature produced.

This mechanism is implemented in hardware wallets such as the BitBox02 and the Blockstream Jade. It is an essential defense against supply chain attacks, where a device's firmware may have been modified before delivery.
