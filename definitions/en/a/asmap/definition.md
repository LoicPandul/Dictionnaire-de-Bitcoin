Tool invented by Gleb Naumenko and used by Bitcoin Core to improve the security and topology of the Bitcoin network by diversifying the connections between nodes. It is a map from IP addresses to autonomous system numbers (ASNs), which allows a better distribution of outbound connections based on ASN rather than on IP prefixes. This helps prevent eclipse attacks (notably the Erebus attack) by making it harder for an attacker to monopolize the connections of a target node through IP addresses belonging to the same autonomous system.
