Attack in which a malicious actor creates an address (or any other payment identifier) that closely resembles the victim's. The goal is to trick the user into copying the wrong address during a transaction, so that the bitcoin goes to the attacker instead of the intended destination.

The attacker exploits the user's haste: a user who makes a transaction without carefully checking the address may copy the wrong one. To set up this attack, the attacker usually makes small payments to the victim's wallet in order to plant the fake address in the victim's transaction history. The attack is mostly used against altcoins, where reusing the same receiving addresses is common, unlike Bitcoin, where using a fresh address for each transaction is the more widespread practice. However, Bitcoin users are not immune to it.

Another way to put the wrong address in front of the victim is to use fraudulent wallet software that imitates legitimate software, or to modify the address on a compromised machine, between the moment it is copied and the moment the transaction is built. This is sometimes called “address swapping”.

To protect against these methods, it is important to check several characters of the address, especially its checksum (at the end), on the screen of the signing device before signing the transaction.

*This attack is also sometimes called address poisoning.*
