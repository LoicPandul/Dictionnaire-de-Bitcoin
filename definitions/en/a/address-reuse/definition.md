Practice of using the same receiving address to lock several UTXOs, sometimes across several different transactions. Bitcoin is generally locked with a cryptographic key pair that corresponds to a single address. Since the blockchain is public, it is easy to look up which addresses are associated with how much bitcoin. When the same address is reused for several payments, it is reasonable to assume that all the associated UTXOs belong to the same entity. Address reuse therefore harms the user's privacy. It makes it possible to draw deterministic links between several transactions and several UTXOs, and to keep tracing funds on-chain. Satoshi Nakamoto already raised this problem in the white paper:

> "As an additional firewall, a new key pair should be used for each transaction to keep them from being linked to a common owner." - Nakamoto, S. (2008). "Bitcoin: A Peer-to-Peer Electronic Cash System". Retrieved from https://bitcoin.org/bitcoin.pdf.

To preserve at least a minimum of privacy, it is strongly recommended to use each receiving address only once. A new address should be generated for each new payment. Change outputs should also use a fresh address. Fortunately, thanks to hierarchical deterministic wallets, using a multitude of addresses has become very easy. All the key pairs associated with a wallet can easily be regenerated from the seed. This is also why wallet software always generates a new, different address when the "Receive" button is clicked.
