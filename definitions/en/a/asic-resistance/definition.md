Property of a mining algorithm that aims to limit the advantage of application-specific integrated circuits (ASICs) over consumer hardware, such as processors (CPUs) or graphics cards (GPUs). The goal is to keep mining decentralized by preventing only actors with expensive, specialized hardware from participating effectively in block validation.

To achieve this resistance, some alternative cryptocurrencies use hash functions that require a lot of RAM (memory-hard), such as Scrypt or Ethash, which makes building ASICs harder or less advantageous. The idea is that if the algorithm demands varied resources (memory, bandwidth, computation), an ASIC does not offer as clear a performance gain as for a simple algorithm like SHA-256.

In the case of Bitcoin, ASIC resistance has never been a goal. Bitcoin uses SHA-256, a function that lends itself very well to hardware optimization. ASICs therefore appeared on the Bitcoin network as early as 2013, which gradually made CPU and GPU mining unprofitable. ASIC resistance remains a subject of debate: its supporters see it as a guarantee of decentralization, while its critics point out that it only delays hardware specialization without ever preventing it durably.
