Algorithmic optimization method invented in 2016, designed to increase the efficiency of Bitcoin mining by about 20% by reducing the amount of computation needed for each block header hashing attempt. This technique exploits a peculiarity of the SHA256 hash function, used for mining, which splits data into blocks before processing them. AsicBoost keeps one of these blocks unchanged across several hashing attempts, which lets the miner do only part of the work for that block across several attempts. This sharing of data allows results from earlier computations to be reused, which reduces the total number of computations needed to find a valid hash.

AsicBoost can be used in two forms: Overt AsicBoost and Covert AsicBoost. Overt AsicBoost is visible to everyone, because it involves using the block's `nVersion` field as an extra nonce. Covert AsicBoost tries to hide these modifications by using Merkle trees. However, this second method has no longer been effective since SegWit, because of the second Merkle tree, which multiplies the number of computations needed to use it.

To sum up, AsicBoost avoids performing a full SHA256 for every hashing attempt, because part of the result stays unchanged, which speeds up the miners' work.
