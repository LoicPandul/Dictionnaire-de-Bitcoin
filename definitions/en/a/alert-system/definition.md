Historical Bitcoin mechanism that made it possible to broadcast emergency messages to all the nodes of the network. Introduced by Satoshi Nakamoto in version v0.3.10, shortly after the value overflow incident of August 2010, this system was used to warn node operators of a critical bug or network problem.

Alerts were relayed over Bitcoin's peer-to-peer network, in the same way as transactions and blocks. Only messages signed with a specific ECDSA private key were considered valid. This key was initially held by Satoshi alone, then shared with a few developers such as Gavin Andresen. In the early versions (up to v0.3.20), a valid alert triggered a “safe mode” that automatically disabled the RPC commands related to transactions, which gave its holders considerable power over the network.

Because of the risk of centralization and the potential for abuse, the system was gradually abandoned: the code was removed in Bitcoin Core v0.13.0, and a final “Alert Key Compromised” alert was broadcast to permanently invalidate any future message. The private key was then made public in 2018.
