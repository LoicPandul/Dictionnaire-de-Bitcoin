Name given to BIP-0118, which proposes adding two new modifier SIGHASH flags, named `SIGHASH_ANYPREVOUT` and `SIGHASH_ANYPREVOUTANYSCRIPT`. Reserved for the so-called "BIP-0118" public keys in Tapscript scripts, they produce a signature that does not commit to the precise output being spent (its transaction ID and index): the same signature remains valid for any other output with a compatible script. With `SIGHASH_ANYPREVOUTANYSCRIPT`, the signature no longer even commits to the amount or the script of the output. This flexibility serves off-chain protocols that prepare a reaction transaction in advance, such as eltoo (LN-Symmetry), where a single signature must be able to spend any earlier update of a channel's state. In 2026, BIP-0118 has Draft status: it is not activated on Bitcoin. The term "AnyPrevOut" comes from the contraction of "Any Previous Output".
