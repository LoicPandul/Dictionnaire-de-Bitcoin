In the RGB protocol, the equivalent of a transaction output that modifies, updates, or creates certain properties within the state of a contract. An assignment has two elements:
* A seal definition (the reference to a specific UTXO);
* An owned state (the data describing the state associated with this new holder).

An assignment therefore indicates that a portion of the state (for example, an asset) is now allocated to a particular holder, identified through a single-use seal tied to a UTXO.
