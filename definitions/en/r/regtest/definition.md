Private test environment for Bitcoin that lets developers create a local Bitcoin network with the same basic rules as testnet. Unlike testnet, a regtest network is private, meaning it is not possible to connect to it freely. It also offers full control over the network parameters. In particular, it allows fast mining of blocks and the testing of specific scenarios. It is used for development, debugging, and experimentation before implementation on testnet or mainnet. The bitcoin circulating on a regtest network has no value.
