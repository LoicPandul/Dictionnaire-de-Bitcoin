Node of the Lightning Network that forwards payments between other nodes, acting as an intermediary in the routing of transactions. When a payment is sent between two users who do not share a direct channel, the Lightning Network identifies a path made up of one or more routing nodes to relay the funds hop by hop through hashed time-locked contracts (HTLCs). Each routing node temporarily locks funds in a channel, then passes them to the next node, possibly collecting small routing fees in return for this service. Routing nodes play an essential role in the connectivity of the Lightning Network, since they make it possible to reach any recipient without needing a direct channel with each counterparty. A good routing node maintains enough liquidity and good connectivity with the other nodes of the network.

Running a routing node can also be a strategy for a node operator who wants to earn revenue from routing fees.
