Open-source web interface for managing a Lightning node from a browser. RTL offers a graphical dashboard for everyday operations: opening and closing channels, sending and receiving payments, managing liquidity, viewing routed payments, and monitoring the node.

RTL is compatible with the three main Lightning implementations: LND, Core Lightning (CLN), and Eclair. It connects to the node's API and provides a unified interface regardless of the underlying implementation.

The tool is often deployed on node-in-a-box solutions such as Umbrel or Start9, which makes it accessible to users who do not want to use the command line. RTL is developed by Shahana Farooqui and distributed under the MIT license.
