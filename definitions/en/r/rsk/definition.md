Bitcoin sidechain designed to run smart contracts compatible with Ethereum. Originally known as Rootstock, this sidechain was renamed RSK before gradually reverting to the name Rootstock.

Launched in January 2018, RSK operates as a sidechain attached to Bitcoin through a two-way peg mechanism, which allows bitcoin to be transferred to the sidechain as RBTC, tokens pegged 1:1 to bitcoin.

RSK uses merged mining: Bitcoin miners can secure the RSK sidechain at the same time, without needing additional computing power. The goal is to extend Bitcoin's functionality with a Turing-complete programmable layer, while taking advantage of the security of Bitcoin's proof of work.
