Layer 2 scaling solution that executes transactions outside the main chain, then publishes data and/or validity proofs on it. The principle is to group (*roll up*) many transactions into batches processed off-chain, while periodically anchoring a cryptographic summary on the base layer to inherit its security guarantees. There are two main families of rollups. Optimistic rollups assume transactions are valid by default and require a proof only when challenged (fraud proof). ZK rollups (or validity rollups) publish with each batch a cryptographic proof (SNARK or STARK) attesting to the validity of all the transactions. The main benefit is a considerable increase in transaction throughput and a reduction in fees, without sacrificing the security offered by the base layer. In the Bitcoin context, projects such as Citrea or Brollups explore this approach, using Bitcoin as a data availability and final settlement layer.
