Company and open-source framework specialized in building general-purpose zero-knowledge proofs. RISC Zero provides a zkVM (zero-knowledge virtual machine) based on the RISC-V instruction set architecture, which can run arbitrary code written in common languages (Rust, C, C++) and cryptographically prove that it was executed correctly. The prover generates STARK proofs, which are then wrapped in SNARK proofs through a Groth16 circuit to reduce their size and ease on-chain verification. Citrea uses RISC Zero's infrastructure to build its Type 2 zkEVM, which lets it prove the validity of each batch of transactions executed on the rollup. RISC Zero also offers Boundless, a decentralized network of provers that makes it possible to outsource proof generation.
