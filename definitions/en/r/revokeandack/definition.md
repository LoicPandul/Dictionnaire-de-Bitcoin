Lightning protocol message exchanged between two peers when a channel's state is updated. When a new payment is routed or an HTLC is resolved, both parties build a new commitment transaction. The `revoke_and_ack` message serves two functions at once: it revokes the old commitment transaction by passing along the corresponding revocation key, and it acknowledges the new state. This mechanism guarantees that, at any moment, only the latest channel state is valid. If a peer tried to publish a revoked state, the revocation key would let the counterparty claim all the funds.
