Acronym for *RACE Integrity Primitives Evaluation Message Digest 160*, where "RACE" stands for *Research and development in Advanced Communications technologies in Europe*. It is a cryptographic hash function that generates a 160-bit hash digest from an arbitrary input. On Bitcoin, it is used to turn a public key into a receiving address for the Legacy and SegWit v0 standards (for SegWit v1, the public key is not hashed). The process first applies the `SHA256` hash function to the public key, then applies `RIPEMD160` to the result. This combination of two distinct hash functions is known as `HASH160` in the Bitcoin context. `RIPEMD160` is also used in hierarchical deterministic wallets to compute key fingerprints. In particular, `HASH160` is used to compute the fingerprint of a parent key, which is then included in the metadata of an extended key (xpub, xprv...).
