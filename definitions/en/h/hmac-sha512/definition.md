Acronym for *Hash-based Message Authentication Code - Secure Hash Algorithm 512*. Cryptographic algorithm used to verify the integrity and authenticity of messages exchanged between two parties. It combines the `SHA512` cryptographic hash function with a shared secret key to generate a unique message authentication code (MAC) for each message.

In the context of Bitcoin, the use of `HMAC-SHA512` departs slightly from its original purpose. The algorithm is used in the deterministic, hierarchical derivation of a wallet's tree of cryptographic keys. `HMAC-SHA512` is used notably to go from the seed to the master key, then for each derivation from a parent pair to child pairs. The algorithm is also found inside another derivation algorithm, `PBKDF2`, which is used to go from the mnemonic phrase and the passphrase to the seed.
