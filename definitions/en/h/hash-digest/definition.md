In cryptography, the result (or output) produced by applying a cryptographic hash function to a set of data. It is a fixed-size string of characters, usually represented as a series of digits and letters in hexadecimal (base 16) notation. This result is almost unique to the input data, so that a minimal change in the input produces a completely different digest. Cryptographic hash functions are designed to be one-way and collision-resistant, making it very hard to recover the original data from the digest or to find two distinct inputs that produce the same digest.
