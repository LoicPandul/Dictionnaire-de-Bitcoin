Base-16 numeral system, which therefore uses 16 distinct symbols to represent numbers. The first 10 symbols are the digits 0 to 9, identical to those of the decimal system (base 10), and the next six are represented by the letters A to F. A thus represents the number 10, B represents 11, and so on up to F, which represents 15. This system is widely used in computing because it offers a more concise representation of binary numbers (base 2), and each hexadecimal digit represents exactly 4 bits, which simplifies conversions. It is very often used to represent information on Bitcoin.
