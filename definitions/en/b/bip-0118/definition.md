Bitcoin improvement proposal introducing two new SIGHASH flag modifiers: `SIGHASH_ANYPREVOUT` and `SIGHASH_ANYPREVOUTANYSCRIPT`. These features extend the capabilities of Bitcoin transactions, particularly for smart contracts and layer 2 solutions such as the Lightning Network. BIP-0118 would notably enable the use of Eltoo. The main advantage of `SIGHASH_ANYPREVOUT` is that it allows signatures to be reused across several transactions, which offers more flexibility. In practice, these SIGHASH flags produce a signature that does not cover any input of the transaction.
