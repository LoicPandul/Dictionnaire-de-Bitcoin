Proposes an authentication mechanism between peers on the Bitcoin network to strengthen security and guarantee node ownership. It lets node operators restrict access to certain services or grant data flow priority only to specific peers, by authenticating each other to avoid MITM attacks. This BIP was closed (`Closed`), but it served as a lesson for BIP-0324 (P2P transport V2), which has been enabled by default in Bitcoin Core since version 27.0.
