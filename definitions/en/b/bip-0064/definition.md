Proposal for a `getutxos` P2P message for querying a node about the state of a specific UTXO. Mike Hearn implemented it in Bitcoin XT. Its version for Bitcoin Core was merged on August 25, 2014 and then removed on August 27, after objections from developers. The BIP itself acknowledges that a remote node can lie by omission, which limits the trust a light client can place in the response.
