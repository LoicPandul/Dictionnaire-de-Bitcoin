Proposal for a new output type called “Pay-to-Merkle-Root” (P2MR), via a soft fork. P2MR works similarly to P2TR (Taproot, BIP-0341), but removes the key path spend. This change is mainly intended to protect funds against long-exposure attacks by quantum computers, which could use Shor's algorithm (or another, still unknown algorithm) to derive private keys from public keys exposed on the blockchain. By removing the internal public key from the output, P2MR prevents this exposure and makes it possible to use Tapscript scripts in a way that resists long-exposure quantum attacks.
