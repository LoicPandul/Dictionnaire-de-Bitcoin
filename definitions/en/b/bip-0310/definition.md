Proposal for extensions to the Stratum protocol used for communication between individual miners (the hashers) and mining pools. BIP-0310 introduces a generic feature negotiation mechanism through a new `mining.configure` message, which lets the miner and the server agree on the supported extensions. The main extension specified is version rolling, which allows miners to modify certain bits of the `nVersion` field of the block header. The BIP also defines other extensions such as minimum difficulty and `subscribe-extranonce`. It is a conceptual predecessor of Stratum V2, which took up and built on these improvements by adding encryption of communications and transaction selection by the hashers.
