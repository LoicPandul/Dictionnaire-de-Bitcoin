Proposes introducing tail call execution semantics into Bitcoin's Script system. This mechanism would let a script transfer execution to another script without increasing the stack depth, in a way analogous to tail call optimization in programming languages. Combined with BIP-0116 (`OP_MERKLEBRANCHVERIFY`), it would offer general MAST capabilities, making it possible to dynamically select and execute a subscript from a set structured as a Merkle tree. This BIP, proposed by Mark Friedenbach in 2017, remained in `Draft` status, while Taproot (BIP-0341) natively integrates Merkle branches.
