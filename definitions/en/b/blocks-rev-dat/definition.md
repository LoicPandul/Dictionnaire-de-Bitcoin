Name of the files in Bitcoin Core that store the information needed to possibly undo the changes made to the UTXO set by previously added blocks. Each file is identified by a unique number that is the same as the blk*.dat file it matches. The rev*.dat files contain the undo data for the blocks stored in the blk*.dat files. This data is essentially a list of all the UTXOs spent as inputs in a block. These undo files let the node roll back to an earlier state in the event of a blockchain reorganization that causes previously valid blocks to be abandoned.
