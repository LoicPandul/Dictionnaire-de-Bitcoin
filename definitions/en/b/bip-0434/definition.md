Proposal for a generic mechanism that lets peers on the Bitcoin network negotiate features when a connection is established. Currently, each new P2P protocol feature requires adding specific messages exchanged after the version handshake. BIP-0434 replaces this ad hoc approach with a unified system in which nodes announce the features they support through a single `feature` message, sent between the `version` and `verack` messages. This simplifies the implementation of new network features and reduces the complexity of the connection protocol between peers.
