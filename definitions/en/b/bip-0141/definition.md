Introduces the concept of Segregated Witness, which gives its name to the SegWit soft fork. BIP-0141 brings to the Bitcoin protocol a major change aimed at solving the transaction malleability problem. SegWit separates the witnesses (signature data) from the rest of the transaction data. This separation is achieved by placing the witnesses in a distinct data structure, committed to in a new Merkle tree, which is itself referenced in the block through the coinbase transaction, which makes SegWit compatible with older versions of the protocol.
