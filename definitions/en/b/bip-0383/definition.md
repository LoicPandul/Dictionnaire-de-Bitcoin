Proposal that introduces the `multi(NUM, KEY, ..., KEY)` and `sortedmulti(NUM, KEY, ..., KEY)` functions for descriptors. These functions describe multisig scripts in descriptors, with `sortedmulti` sorting the public keys in lexicographic order to ensure compatibility on import. BIP-0383 was implemented, along with all the other descriptor-related BIPs (except BIP-0386), in Bitcoin Core version 0.17.
