Probabilistic data structure used to test whether an element belongs to a set. Bloom filters make it possible to check membership quickly without testing the whole data set. They are particularly useful in contexts where space and speed are critical but a low, controlled error rate is acceptable. Bloom filters produce no false negatives, but they do produce a certain amount of false positives. When an element is added to the filter, several hash functions generate positions in a bit array. To check membership, the same hash functions are used. If all the corresponding bits are set, the element is probably in the set, but with a risk of false positives. Bloom filters are widely used in databases and networking. Google is known to use them in BigTable, its distributed storage system for structured data. In the Bitcoin protocol, they are notably used by SPV wallets under BIP-0037.

*The use of Bloom filters specifically with Bitcoin transactions is sometimes called "transaction Bloom filtering".*
