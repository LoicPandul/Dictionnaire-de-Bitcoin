Proposal that introduced the concept of the hierarchical deterministic (HD) wallet. It makes it possible to generate a hierarchy of key pairs from a common seed, the master seed, using one-way derivation functions. Each generated key pair can itself be the parent of other child keys, forming a tree (hierarchical) structure. The advantage of BIP-0032 is that it manages many different key pairs while requiring only a single seed to be kept in order to regenerate them. This innovation notably helped combat address reuse, which is seriously harmful to users' privacy. BIP-0032 also allows sub-branches to be created within a single wallet to make it easier to manage.
