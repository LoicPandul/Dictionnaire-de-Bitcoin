Specific BIP-0032 derivation path for timelocked fidelity bonds, used in the JoinMarket protocol. The funds are locked with `OP_CHECKLOCKTIMEVERIFY`, proving a temporary economic sacrifice by the maker. This sacrifice raises the maker's reputation and priority in the coinjoin protocol, since it demonstrates a real financial commitment. BIP-0046 standardizes the derivation path `m/84'/0'/0'/2/index`, where the index (from 0 to 959) corresponds to a month between January 2020 and December 2099, which determines the timelock of the address. This scheme lets fidelity bonds be kept in cold storage, because the user only needs to back up their seed and the reference to this BIP, without having to remember the lock dates. This BIP currently has `Draft` status.
