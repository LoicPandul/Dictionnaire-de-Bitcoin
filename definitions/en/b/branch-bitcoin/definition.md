In Bitcoin, a sequence of valid blocks in which each new block is linked to the previous one. The blockchain is the branch that contains the most accumulated work, but competing branches resulting from forks can exist. Every branch shares at least one block with the main branch, namely the genesis block. The part of a branch made of blocks unique to it is sometimes called the "segment". When two competing branches are present, honest nodes synchronize on the one with the most accumulated work. A branch is sometimes described as "strong" if it has more accumulated work than another, and "weak" otherwise.
