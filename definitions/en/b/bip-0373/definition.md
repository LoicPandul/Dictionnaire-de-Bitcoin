Proposal that adds MuSig2-specific fields (BIP-0327) to the PSBT format to allow collaborative signing through hardware wallets and coordinators. These fields include the participants' public keys, public nonces, and partial signatures. BIP-0373 thus makes it possible to coordinate the two-round MuSig2 protocol by exchanging PSBT files, without the different signers needing to interact directly with each other.
