Sequence number of a particular block relative to the first block, known as the genesis block, which is indexed at height zero. This number gives the count of blocks that precede the block in question. For example, if a block is at height 650,000, it means 650,000 blocks precede it. Block height is used to identify a specific block within the blockchain. Contrary to a common belief, block height does not determine which chain is valid, because nodes synchronize on the chain that has accumulated the most work, not on the longest chain.
