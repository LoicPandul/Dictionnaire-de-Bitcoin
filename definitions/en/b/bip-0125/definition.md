Defines the concept of Replace-by-Fee (RBF), which lets the sender replace an unconfirmed transaction with another version that includes higher transaction fees. BIP-0125 provides a framework for signaling RBF in a transaction and for its acceptance by the nodes of the network. Since Bitcoin Core 28.0, the `mempoolfullrbf=1` option is enabled by default: a node then accepts the replacement of a transaction even if it did not signal replaceability.
