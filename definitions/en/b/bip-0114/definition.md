First formal proposal for MAST (Merkelized Abstract Syntax Tree) on Bitcoin, presented by Johnson Lau in 2016. BIP-0114 made it possible to structure the spending conditions of a UTXO as a Merkle tree, where each leaf represents an alternative script. When spending, only the executed branch had to be revealed, while the others remained hidden. This improved privacy and reduced the size of complex transactions. This BIP was closed in favor of BIP-0341 (Taproot), which integrates the MAST concept more elegantly through its script path.
