Cryptographic protocol in which an oracle performs operations (signing, encryption) on a confidential message sent by a user, without being able to learn its content. The user can then verify the validity of the result without having exposed the original message to the oracle. This mechanism generally relies on blind cryptography techniques, such as blind signatures or commitment schemes.

In the context of Bitcoin, the blind oracle concept is used notably in Blockstream's Jade hardware wallet. The wallet encrypts the mnemonic phrase locally and uses a remote oracle for PIN protection, without that oracle having access to the private keys or the mnemonic phrase. This approach amounts to a “virtual secure element” that aims to protect against physical attacks, without requiring a dedicated secure chip.
