Proposal to forbid 64-byte transactions in order to fix a vulnerability in the verification of Merkle trees. A serialized 64-byte transaction can be mistaken for an internal node of the Merkle tree, because both are the same size. This ambiguity could potentially allow fraudulent SPV proofs to be built that fool light clients. BIP-0054, a set of fixes to the consensus rules ("consensus cleanup"), takes up the same rule.
