Protocol for using Payjoin on Bitcoin, a transaction structure that improves the privacy of payments by having the recipient contribute inputs alongside the payer's. This BIP draws on BIP-0079, which had already presented a similar concept. However, neither of these two BIPs marks the origin of the Payjoin concept. Indeed, the Stowaway implementation in Samourai Wallet already existed, and this transaction structure had first been mentioned by LaurentMT in 2015 under the name “steganographic transaction”.
