Proposal that changes transaction relay to use the `wtxid` (witness transaction identifier) instead of the classic `txid` when announcing and requesting transactions between peers. Before this BIP, a malicious peer could send invalid witnesses for a valid `txid`, wasting the receiving node's bandwidth. With the `wtxid`, whose computation includes the SegWit witness data, each witness variant has a unique identifier, which prevents this class of denial-of-service attacks. Nodes signal their support through the `wtxidrelay` message exchanged during the version handshake.
