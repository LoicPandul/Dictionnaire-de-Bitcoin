Proposal defining the BSMS (Bitcoin Secure Multisig Setup) protocol, a standard for the secure setup of multisig wallets across different hardware and software signers. The protocol uses an encryption scheme and token-based coordination to exchange extended public keys and the wallet configuration. It ensures that all cosigners agree on the same parameters (signature threshold, descriptor, derivation paths) before the wallet creation is finalized. BIP-0129 is adopted by several software products such as Nunchuk and Sparrow.
