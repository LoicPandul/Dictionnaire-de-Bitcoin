Proposal that defines how to build a synthetic BIP-0032 extended public key (xpub) from a MuSig2 aggregate public key (BIP-0327), and how to use it to derive child keys. Rather than requiring each participant to derive their individual keys before aggregating them at each level, BIP-0328 allows non-hardened child keys to be derived directly from a single synthetic xpub built on the aggregate key. This xpub uses a fixed, standardized chain code. The mechanism greatly simplifies receiving address generation in MuSig2 multisig wallets, reducing the storage and computation required. When signing, participants must compute the corresponding BIP-0032 derivation tweaks and provide them in the MuSig2 session context.
