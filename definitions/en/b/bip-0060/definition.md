Proposal to fix the size of the `version` message of the Bitcoin P2P protocol and to cleanly include in it a boolean `relay` field, which indicates whether the node wants to receive the unconfirmed transactions relayed by its peers. BIP-0060 recommended a fixed-size approach to guarantee backward compatibility of the handshake between nodes of different versions.

In practice, BIP-0037 (Bloom filters) had already added this `relay` field to the `version` message, but in a way that was not backward compatible: older nodes that validated the message size failed the handshake with newer nodes. In addition, the implementation was inconsistent across protocol versions (version 70001 read `relay` without writing it, while 70002 did both). BIP-0060 proposed to correct this situation, but since BIP-0037 had already broken compatibility irreversibly, retroactively applying the approach of BIP-0060 was no longer worth the effort. Its status is therefore `Closed`.
