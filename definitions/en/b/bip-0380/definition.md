Improvement proposal that introduces a standard language for describing collections of output scripts in Bitcoin HD wallets. This language is called “Output Script Descriptors”. It aims to standardize how output scripts are represented and managed, to make wallet backup, export, and import easier. Together with private data such as the mnemonic phrase, descriptors provide all the information needed to recover the key pairs used in an HD wallet. BIP-0380 describes how descriptors work in general, while BIP-0381, BIP-0382, BIP-0383, BIP-0384, BIP-0385, and BIP-0386 specify the expressions they use. BIP-0380 was implemented, along with all the other descriptor-related BIPs (except BIP-0386), in Bitcoin Core version 0.17.
