Proposal that rewrites the `bitcoin:` URI scheme defined by BIP-0021, which it replaces, in order to describe the modern uses of these URIs: standard query parameters, SegWit addresses in bech32 and bech32m format, new payment instructions, and optional proof of payment. The original BIP-0021 was designed for Base58 addresses, which are case-sensitive. Since bech32 addresses are case-insensitive, BIP-0321 adapts the specification to allow their correct use in URIs, notably in QR codes, where uppercase encoding is more efficient. This BIP ensures the compatibility of the Bitcoin URI scheme with modern address formats.
