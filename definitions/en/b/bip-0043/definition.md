Improvement proposal that introduces a derivation level to describe the purpose (the `purpose` field) in the structure of HD wallets, previously introduced in BIP-0032. According to BIP-0043, the first derivation level of an HD wallet, right after the master key denoted `m/`, is reserved for the purpose number, which indicates the derivation standard used for the rest of the path. This number is recorded as a hardened index. For example, if the wallet follows the SegWit standard (BIP-0084), the start of its derivation path will be `m/84'/`. BIP-0043 thus clarifies which standards each wallet software follows, for better interoperability between them. The standardization of the rest of the derivation path is described in BIP-0044.
