Proposes adding the `OP_MERKLEBRANCHVERIFY` opcode to Bitcoin's script system. This opcode verifies an inclusion proof in a Merkle tree directly within a script. In practice, it takes a root hash, a branch proof, and a value from the stack, then verifies that the value does belong to the tree identified by the root. Combined with other opcodes, it would make it possible to build MAST (Merkelized Abstract Syntax Tree) structures directly in Script. This BIP, proposed by Mark Friedenbach in 2017, remained in `Draft` status, while Taproot (BIP-0341) natively integrates the MAST concept.
