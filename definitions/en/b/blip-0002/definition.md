bLIP that establishes a value reservation registry to avoid conflicts between the different Lightning Network proposals. Without coordination, two bLIPs could use the same message identifier, the same feature bit, or the same TLV type, causing network incompatibilities. bLIP-0002 centralizes reservations in four categories: feature bits (above 255), message types (range 32768-65535), TLV extension fields of existing BOLT messages (`init`, `payment_onion_payload`, `update_add_htlc`, `ping`), and onion message payloads. Each entry is linked to the bLIP that uses it.
