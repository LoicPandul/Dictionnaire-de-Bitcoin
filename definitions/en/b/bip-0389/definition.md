Proposal that extends output script descriptors with multipath key expressions using the `<M;N>` syntax. For example, `<0;1>` in a derivation path represents both receiving addresses (index 0) and change addresses (index 1) within a single descriptor. Without this extension, a single wallet would need two separate descriptors. BIP-0389 thus simplifies wallet backup by reducing it to a single string that contains all the information needed to rebuild the addresses.
