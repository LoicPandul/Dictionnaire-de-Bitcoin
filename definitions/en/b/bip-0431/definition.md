Informational BIP that describes transaction pinning attacks and proposes topological restrictions on transaction packages in the mempool to mitigate this type of attack. Pinning is a technique in which an attacker exploits the limitations of mempool policies to prevent a legitimate transaction from being confirmed, which is a problem notably for higher-layer protocols such as Lightning.

BIP-0431 defines TRUC (Topologically Restricted Until Confirmation) transactions, signaled by `nVersion=3`. An unconfirmed TRUC transaction can have only one unconfirmed ancestor and one unconfirmed descendant, which must also be TRUC. Its virtual size is limited to 10,000 vB, and to 1,000 vB if it depends on an unconfirmed TRUC parent. These constraints make transaction replacement more predictable and reliable, which helps protocols that depend on the quick confirmation of transactions.
