Proposal for a private payment protocol that uses a payment code published by the recipient on the network. The payer derives a unique address for the recipient without prior interaction, after a notification transaction, an `OP_RETURN` output of 40 bytes. BIP-0351 is an alternative approach to Silent Payments (BIP-0352), with different trade-offs: it requires an on-chain notification transaction, which the recipient must find by scanning the blocks. The BIP repository set its status to `Closed` in July 2026. Both proposals aim to eliminate address reuse while preserving the recipient's privacy.
