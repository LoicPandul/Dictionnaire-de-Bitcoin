BIP proposed by Patrick Strateman and Amir Taaki in 2011 that aims to distinguish client version numbers from protocol version numbers. BIP-0014 specifies how implementations of the Bitcoin protocol should present themselves on the network. It suggests using a user agent format to identify the version and type of the Bitcoin client in use. The main goal of BIP-0014 is to make it easier to manage changes and detect incompatibilities between the various existing clients. While it had previously been reasonable to treat Satoshi's client as the de facto Bitcoin protocol, the proliferation of software at the time led BIP-0014 to clearly separate the clients from the protocol itself.
