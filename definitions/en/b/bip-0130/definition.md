Proposal adding the `sendheaders` P2P message to Bitcoin's network protocol. This message lets a node ask its peer to announce new blocks directly through `headers` messages, rather than through `inv` messages followed by an explicit request. This mechanism reduces block propagation latency by eliminating an extra network round trip. The receiving node can thus start validating the block header immediately after the announcement. BIP-0130 has been deployed and active on the Bitcoin network since 2016.
