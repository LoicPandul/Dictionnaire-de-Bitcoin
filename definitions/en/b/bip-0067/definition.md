Proposal specifying that the public keys within a P2SH multisignature `redeemScript` must be sorted in lexicographic order. This sorting guarantees that all cosigners generate the same multisig address, regardless of the order in which the keys are inserted when the script is created. Without this standard, different key orders would produce different `redeemScript` values and therefore different addresses, which would prevent interoperability between wallet software.
