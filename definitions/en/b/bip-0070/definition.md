Interactive payment protocol for Bitcoin. It allows payment requests to be sent and payments to be received in a secure and standardized way. In this protocol, the customer clicks a Bitcoin URI (BIP-0021) extended with an additional parameter (described in BIP-0072). The payment request is signed with the merchant's SSL certificate. When this request is received and validated, the payment details are automatically filled in the transaction interface of the customer's wallet. This protocol provides a payment confirmation and improves security and user experience by making clear who the payee is. The method proposed in BIP-0070 was never widely adopted by merchants.
