Informational BIP that defines a new standard output type called "Pay-to-Anchor" (P2A). It is a SegWit version 1 output whose script is `OP_1 <0x4e73>` (a 2-byte witness program, or 4 bytes for the complete script) and which anyone can spend. This output type is specifically designed to serve as an anchor for the Child Pays For Parent (CPFP) mechanism: any participant can create a child transaction spending this output to increase the effective fees of the parent transaction. P2A replaces Lightning-specific anchor outputs with a universal mechanism, usable by any protocol that needs to adjust fees after a pre-signed transaction has been created.
