Process in which a user signs a Bitcoin transaction without being able to verify precisely the details of what is being signed. With hardware wallets, blind signing is dangerous, because the user has to rely on the connected computer to display the information (recipients, fees, amounts...). This exposes the user to vulnerabilities, since the computer is connected to the internet and has a much larger attack surface than the signing device. If the computer is compromised, it can manipulate the displayed details and send a malicious transaction to be signed without the user being aware of it. To avoid this risk, it is recommended to use hardware wallets with a built-in screen and to check the information on that screen before signing transactions.
