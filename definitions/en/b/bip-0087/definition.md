Proposal defining the derivation path `m/87'/coin_type'/account'` specifically for multisig wallets that use output script descriptors. Unlike BIP-0048, which encodes the script type in the derivation path, BIP-0087 takes a simpler approach by delegating the specification of the script type to the descriptor itself. This design is better suited to the modern wallet ecosystem, which relies on descriptors to describe spending conditions precisely.
