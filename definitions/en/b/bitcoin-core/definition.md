Open-source reference software for the Bitcoin system and the main implementation of the Bitcoin protocol in 2026. It is developed and maintained by a large group of volunteer contributors. Originally named “Bitcoin Qt”, Bitcoin Core is the third client in Bitcoin's history, after Bitcoin, by Satoshi Nakamoto, and Bitcoind. It was developed from Satoshi's original code and introduced a graphical user interface. In 2026 (Bitcoin Core 31), Bitcoin Core's graphical interface is still called `bitcoin-qt`. It has shipped with `bitcoind` since version 0.5. Bitcoin Core serves several purposes. First, it acts as a full node client. Bitcoin Core also includes a wallet for users who want to store, manage, and make transactions directly with Bitcoin Core.
