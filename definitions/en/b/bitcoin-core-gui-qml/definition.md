Experimental project, launched in 2021 and still under development as of October 2026, to create a Bitcoin wallet and node application built on Bitcoin Core, but with an intuitive graphical interface developed using QML (Qt Modeling Language). The goal of Bitcoin Core GUI-QML is to modernize Bitcoin Core's user interface to offer a simpler, smoother, and more dynamic experience.

Bitcoin Core's traditional interface is mainly developed in C++ with Qt Widgets, a system that produces very classic user interfaces. The new project now builds on QML, a declarative language used to design GUIs with animations, transitions, and a more responsive, stylized interface. This will bring Core closer to modern application interfaces with rich interactions. The goal is for the software to be available on both PC and mobile.
