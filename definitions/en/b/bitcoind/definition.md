Bitcoin Core daemon, that is, software that implements the Bitcoin protocol and lets users run a node that answers remote procedure calls (RPC). It is a command-line program (with no GUI) that serves as a communication interface with Bitcoin. In other words, it is a program that runs in the background and that the user can interact with. `Bitcoind` was part of Satoshi Nakamoto's original client. Some consider it the second client in Bitcoin's history, after Satoshi's first, since version 0.2.7, from February 2010, was the first to offer a build without a graphical interface, named `bitcoind`. It was later bundled with Bitcoin QT in 2011, a client that was itself renamed “Bitcoin Core” in 2014. Today, `bitcoind` is therefore fully integrated into the Bitcoin Core client.
