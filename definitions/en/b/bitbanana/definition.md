Open-source Android application for managing a Lightning node remotely from a phone. Born as a fork of the Zap Android wallet (created by Jack Mallers), the project was taken over and renamed by developer Michael Wünsch to pursue independent development. The application provides a full interface for monitoring and controlling a node: channel management, sending and receiving payments, viewing logs, and routing statistics. BitBanana is compatible with LND, Core Lightning, and Nostr Wallet Connect, which makes it a versatile tool for Lightning node operators.
