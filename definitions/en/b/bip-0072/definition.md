Extension of Bitcoin URIs (BIP-0021) with an additional `r` parameter, completing BIP-0070 and BIP-0071. This parameter makes it possible to include a link to a secure payment request signed with the merchant's SSL certificate. When a customer clicks this extended URI, their wallet contacts the merchant's server to request the payment details. These details are automatically filled in the wallet's transaction interface, and the customer can be informed that they are paying the owner of the domain matching the signing certificate (for example, "pandul.fr"). Since this improvement was bundled with BIP-0070, it was never widely adopted.
