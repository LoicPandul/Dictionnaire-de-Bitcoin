Standard for interacting with tokens that are not native to Bitcoin, based on inscriptions of the Ordinals protocol. Created by Domo in March 2023, this experimental standard set off strong speculative enthusiasm, causing a historic rise in transaction fees in April and May 2023. BRC-20 tokens use Bitcoin to store and timestamp JSON functions that manage these assets. The functions are `deploy` (token creation), `mint` (token issuance), and `transfer` (token transfer). To run this protocol, people must maintain servers that index all the functions. The BRC-20 standard is therefore a very inefficient use of Bitcoin compared with other token creation protocols such as RGB.
