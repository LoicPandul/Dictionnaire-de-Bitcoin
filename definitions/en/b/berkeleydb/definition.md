Embeddable database management system with a key-value storage architecture. It was used in the first versions of Bitcoin to store the block and transaction indexes as well as the wallet. LevelDB replaced it for the indexes starting with Bitcoin Core 0.8.0, in 2013, but BerkeleyDB remained the format of legacy wallets until Bitcoin Core 30.0, which can no longer create or load them (they are migrated to the descriptor format).
