Class of error-correcting codes used to detect and correct errors in a sequence of data. In other words, BCH error-correcting codes make it possible to find and correct random errors in transmitted information, so that it arrives intact at its destination. The acronym "BCH" stands for the initials of the codes' inventors: Bose, Ray-Chaudhuri, and Hocquenghem.

This tool is used in many areas of computing, notably in SSDs, DVDs, and QR codes. For example, thanks to these error-correcting codes, even if a QR code is partially covered, the information it encodes can still be recovered.

In Bitcoin, BCH codes are used for the checksum in the Bech32 and Bech32m address formats (native SegWit). They offer a better trade-off between size and error-detection capability than the simple hash functions previously used on Legacy addresses. In the context of Bitcoin, BCH codes are used only for error detection, not for error correction. Wallet software therefore identifies and reports to the user any error in a receiving address, but does not modify the incorrect address automatically. This choice is motivated by the fact that integrating error correction inevitably affects the error-detection capabilities of the algorithm.
