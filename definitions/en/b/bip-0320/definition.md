Proposal to reserve certain bits of the `nVersion` field of block headers for general use, separate from the soft fork signaling mechanism defined by BIP-0009. The main motivation of BIP-0320 is to allow Overt ASICBoost to be used cleanly: this mining optimization technique requires modifying the block's version bits, which can interfere with soft fork signaling. By reserving dedicated bits, miners can use ASICBoost without ambiguity with the activation mechanisms.
