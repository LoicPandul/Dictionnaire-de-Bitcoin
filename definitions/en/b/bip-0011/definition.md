BIP introduced by Gavin Andresen in 2011 that proposes a standard method for creating multisignature transactions on Bitcoin. This proposal improves the security of bitcoin by requiring several signatures to validate a transaction. BIP-0011 introduces a new script type, named "M-of-N multisig", where `M` is the minimum number of signatures required out of `N` potential public keys. This standard uses the `OP_CHECKMULTISIG` opcode, which already existed in Bitcoin but previously did not comply with node standardness rules. Although this script type is no longer commonly used for real multisig wallets, having given way to P2SH or P2WSH, it remains possible to use it. It is notably used in metaprotocols such as Stamps. Nodes can nonetheless choose not to relay these P2MS transactions with the `permitbaremultisig=0` option.

*Today, this standard is known as "bare multisig" or "P2MS".*
