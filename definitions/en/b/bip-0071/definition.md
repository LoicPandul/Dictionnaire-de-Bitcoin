MIME (Multipurpose Internet Mail Extensions) media type, defined in accordance with RFC 2046, for the bitcoin payment request messages of BIP-0070. MIME is an Internet standard that extends the format of email messages so that various types of data can be sent in a structured way. In BIP-0071, adopting a specific MIME type for payment messages ensures that wallet software, when sending payment protocol messages by email or HTTP, follows Internet standards for proper message encapsulation. Since this improvement was bundled with BIP-0070, it was never widely adopted.
