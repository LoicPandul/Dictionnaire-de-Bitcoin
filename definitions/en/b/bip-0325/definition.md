Proposal that defines Signets, test networks for Bitcoin in which block production is controlled by a set of authorized signers, in addition to proof of work. Unlike the classic testnet, where anyone can mine and cause unpredictable reorganizations, blocks on Signet must contain a valid signature from designated keys. This makes the network stable, predictable, and suited to developing and testing applications. The default signet is maintained by Kalle Alm and AJ Towns. Custom signets can be created with their own signing keys.
