`Bitcoin-cli` is a command-line interface (hence the `cli`) designed to interact with a running instance of Bitcoin Core, in particular the daemon, `bitcoind`. It is a standalone program that gives the user a way to communicate with the instance of `bitcoind`, run commands, and query its state. It sends these commands as remote procedure calls (RPC): the node executes them, whether to query the network, the blockchain or, if the node has a wallet, to manage that wallet, create transactions, and send or receive funds.
