Proposal to redefine Bitcoin's base unit so that “1 bitcoin” corresponds to today's satoshi, eliminating decimals altogether. Under this new system, the current value of 1 BTC would become 100,000,000 of the new base unit. BIP-0177 aims to simplify the user experience by removing the confusion caused by decimal fractions, which is particularly problematic for new users.

This change has been adopted by some applications, notably Bitkit, the wallet developed by Synonym, whose CEO, John Carvalho, is also the author of BIP-0177. In practice, however, the vast majority of wallet software still keeps the standard of 1 bitcoin = 100,000,000 satoshis.
