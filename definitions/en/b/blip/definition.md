Acronym for *Bitcoin Lightning Improvement Proposal*. bLIPs are standardization proposals for Lightning Network features that do not require universal adoption, unlike BOLTs. They are used to document application extensions, optional protocols, or usage conventions between compatible implementations. The process of creating a bLIP follows a community review cycle: an author submits a draft to the dedicated GitHub repository, where it is evaluated, then progresses from Draft to Proposed and then Active depending on consensus and adoption. bLIPs complement BOLTs by offering a lighter and more flexible framework to propose innovations without modifying the core specifications of the protocol.
