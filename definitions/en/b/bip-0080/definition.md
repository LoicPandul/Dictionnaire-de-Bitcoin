Closed proposal defining a hierarchical deterministic derivation path (BIP-0032) for deterministic multisig wallets used in “voting pools” without colored coins. A “voting pool” is a mechanism for collaboratively managing funds in cold storage on a FIFO basis, where several participants share control of multisig wallets. BIP-0080, a specific application of BIP-0043 based on BIP-0044, defines the path `m / purpose' / coin_type' / series' / address_index`, which lets each participant derive keys in a coordinated way to build the multisig deposit scripts. This highly specialized proposal was never widely adopted by the Bitcoin ecosystem.
