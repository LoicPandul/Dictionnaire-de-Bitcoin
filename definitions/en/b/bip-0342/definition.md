Proposal that defines Tapscript, the scripting language used for script path spends in Taproot (BIP-0341). Tapscript makes several changes compared with traditional Bitcoin Script. It replaces `OP_CHECKMULTISIG` and `OP_CHECKMULTISIGVERIFY` with `OP_CHECKSIGADD`, a new opcode that makes batch verification of Schnorr signatures easier. BIP-0342 also introduces `OP_SUCCESS` opcodes, which reserve ranges of opcodes for future protocol extensions without requiring a complex soft fork. Signature verification relies on the Schnorr scheme defined in BIP-0340. Tapscript also removes the 10,000-byte script size limit and the 201 non-push opcode limit that applied to legacy scripts, giving developers more flexibility.
