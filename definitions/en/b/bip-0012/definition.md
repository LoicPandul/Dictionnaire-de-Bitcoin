Proposal by Gavin Andresen to improve the flexibility and privacy of Bitcoin transaction scripts. This BIP proposes implementing a new script opcode, named `OP_EVAL`, which evaluates a script contained in the data of a `scriptSig` during transaction validation. The main change in BIP-0012 is to allow a script to be included inside another script. This technique makes it possible to create more complex conditions that are checked at spending time, without having to reveal them to the users who send bitcoin to the address in question. BIP-0012 was later replaced by other, safer proposals, notably BIP-0016 (P2SH), which offers a different method for reaching the same goals as `OP_EVAL`.
