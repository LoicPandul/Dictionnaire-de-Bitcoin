Improvement proposal by Josibake, Ruben Somsen, and Sebastian Falbesoner that introduces Silent Payments, a method for using static Bitcoin addresses to receive payments without address reuse, without interaction, and without a visible on-chain link between the different payments. This technique removes the need to generate a new, unused receiving address for every transaction, which avoids the usual Bitcoin interaction in which the recipient must give the payer a new address.

In this system, the payer uses the recipient's public key and their own private key to generate a fresh address for each payment. Only the recipient, using their private key, can compute the private key matching this address. ECDH (Elliptic-Curve Diffie-Hellman), a cryptographic key exchange algorithm, is used to establish a shared secret, which then serves to derive the receiving address and the private key (on the recipient's side only). To identify the Silent Payments intended for them, recipients must scan the blockchain and examine every transaction that meets the Silent Payments criteria. Unlike BIP-0047, which uses a notification transaction to set up the payment channel, Silent Payments remove this step, which saves a transaction. The trade-off, however, is that the recipient must scan all potential transactions to determine, by applying ECDH, whether they are addressed to them.
