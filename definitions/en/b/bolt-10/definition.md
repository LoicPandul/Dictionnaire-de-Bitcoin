Specification that defines a DNS-based discovery mechanism for Lightning nodes. It lets a node that starts with no known contacts find its initial peers (bootstrap) by querying authoritative DNS servers (DNS seeds). It also provides for Assisted Node Location, which helps a node find the current address of an already known peer. Queries support filters by address type (IPv4, IPv6), by specific node ID, and by the number of results wanted. DNS servers return a random sample of healthy nodes, with IP addresses in `A`/`AAAA` records (standard port `9735`) and `SRV` records for non-standard ports.
