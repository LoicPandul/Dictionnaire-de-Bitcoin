Proposal defining a specific BIP-0032 derivation path for deterministic P2SH multisignature wallets. The path used is `m/45'/cosigner_index/change/address_index`, where each cosigner is assigned a distinct index. This structure lets all participants deterministically generate the same multisig addresses, without any further communication after the initial exchange of extended public keys. BIP-0045 has been largely superseded by BIP-0048 and BIP-0087, which offer better support for the different script types.
