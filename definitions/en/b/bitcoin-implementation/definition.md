Software that applies and follows the rules defined by the Bitcoin protocol. What is generally called "Bitcoin" is the electronic cash system. It is a protocol that specifies rules. Concretely, it is represented by nodes that form a network. This system has no code of its own. It is simply a set of broad, tacit rules enforced by the consensus of users through their nodes. What does have computer code, and can therefore be developed, maintained, and modified, is rather the Bitcoin node software. These are independent implementations of the Bitcoin protocol that can connect to the rest of the network.

Among Bitcoin implementations, Bitcoin Core is by far the most widespread, since it runs the vast majority of the node network: in September 2025, Coin.dance counted about 77% of reachable nodes running it, against about 23% for Bitcoin Knots. However, there are also minority implementations such as btcd, Bcoin, and Bitcoin Knots. Despite the diversity of software clients available, the predominance of Bitcoin Core on the network gives it an almost exclusive influence over how the Bitcoin protocol is applied. Bitcoin Core is therefore said to represent, in practice, the Bitcoin protocol itself.
