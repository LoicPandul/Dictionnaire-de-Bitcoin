Soft fork applied in March 2013 that introduced version 2 for Bitcoin blocks. The last version 1 block is block 227,835. This new version requires each block to include, in the `scriptSig` of its coinbase transaction, the height of the block being created. On the one hand, this change clarifies how the network agrees to modify the structure of blocks and the consensus rules. On the other hand, it enforces the uniqueness of each block and each coinbase transaction.
