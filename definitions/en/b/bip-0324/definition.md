Proposal that introduces a new version of the Bitcoin P2P transport protocol with opportunistic encryption, to improve the privacy and security of communications between nodes. The BIP-0324 V2 P2P transport was included in Bitcoin Core version 26.0, released in December 2023, where it was disabled by default. It has been enabled by default since version 27.0 (April 2024), and the `v2transport=0` option disables it. This improvement replaces BIP-0151.
