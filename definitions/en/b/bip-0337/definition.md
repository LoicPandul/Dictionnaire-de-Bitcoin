Proposal for a compression format for Bitcoin transactions, which significantly reduces their size by omitting data that is redundant or deducible from context. The BIP combines four methods: grouping the metadata of the transaction, of each input, and of each output; replacing 32-bit numbers with variable-length integers; compressing signatures, the public key being recovered at decompression; and replacing the outpoint (the `txid` and the output index, 36 bytes) with a block height and an index. The compressed transaction can fall below 50% of the original size, but outpoint compression is optional and can lose information. This BIP, written by Tom Briar, has `Draft` status in the BIP repository.
