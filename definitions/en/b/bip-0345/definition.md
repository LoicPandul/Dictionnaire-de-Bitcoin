Proposal to add two opcodes, `OP_VAULT` and `OP_VAULT_RECOVER`, that make it possible to create native “vaults” on Bitcoin. A vault is a security mechanism that imposes a waiting period when withdrawing funds: during this period, the owner can cancel the transaction and redirect the funds to a predefined recovery address. This system protects against theft by providing a window to react even if the main keys are compromised. Proposed by James O'Beirne and Greg Sanders, BIP-0345 was closed in favor of `OP_CHECKCONTRACTVERIFY` (BIP-0443).
