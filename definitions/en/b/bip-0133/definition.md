Proposal adding the `feefilter` P2P message to Bitcoin's network protocol. This message lets a node tell its peers the minimum fee rate it accepts for transaction relay. When a node receives a `feefilter`, it refrains from sending transactions whose fees are below the indicated threshold. This mechanism reduces bandwidth consumption by avoiding the transmission of transactions that the peer's mempool would reject anyway. BIP-0133 has been deployed and active on the Bitcoin network since Bitcoin Core version 0.13.0.
