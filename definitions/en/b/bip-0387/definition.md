Proposal that defines the output script descriptors `multi_a()` and `sortedmulti_a()` for multisig in Tapscript using the `OP_CHECKSIGADD` opcode. These descriptors are the equivalent of `multi()` and `sortedmulti()` used in traditional scripts, but adapted to Taproot script path spending. The `sortedmulti_a()` variant sorts the public keys in lexicographic order to guarantee a deterministic result.
