Reject message introduced into the communication protocol between nodes. The goal of BIP-0061 is to add a feedback mechanism for when a node receives, from another node, a transaction or block that it considers invalid. This reject message would let a node tell the sender why the transaction or block was rejected. This type of communication was meant to improve interoperability between the different clients and communication between full nodes and SPV clients. The features brought by BIP-0061 were ultimately dropped as of Bitcoin Core version 0.20.0, because they were considered unnecessary while requiring more bandwidth.
