Proposal (draft) that describes a P2P protocol for relaying packages of related transactions (ancestor packages). This BIP makes it possible to relay a low-fee parent transaction together with its higher-fee child transaction, which makes the Child Pays For Parent (CPFP) mechanism effective at the network relay level. Without this protocol, a parent transaction whose fees are below the mempool minimum cannot be propagated, even if a child transaction is ready to compensate. BIP-0331 solves this problem by allowing nodes to evaluate the fee rate of the whole package rather than of each transaction individually.
