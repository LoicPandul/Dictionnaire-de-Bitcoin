BIP written by Salvatore Ingala that proposes adding `OP_CHECKCONTRACTVERIFY` (CCV), a general-purpose opcode for implementing covenants on Bitcoin. CCV verifies that a transaction output respects a contract defined by a combination of a hash and data embedded in the Taproot public key through the tweaking mechanism. Unlike earlier proposals aimed at a specific use case, CCV offers a flexible framework that can serve multiple constructions: vaults with a recovery mechanism, improved Lightning channels, payment pools, and other protocols that need to introspect transaction outputs.
