Proposal that introduces the `combo(KEY)` function for descriptors. This function describes a set of possible output scripts for a given public key, so it covers several script types at once, notably P2PK, P2PKH, P2WPKH, and P2SH-P2WPKH. If the given key is compressed, all 4 script types are tested; if it is not, only the 2 legacy script types are. The goal is to simplify the representation of keys in descriptors by providing a single method to generate different output script variants based on the same public key. BIP-0384 was implemented, along with all the other descriptor-related BIPs (except BIP-0386), in Bitcoin Core version 0.17.
