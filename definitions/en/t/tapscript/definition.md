Update that modifies certain opcodes of Bitcoin's classic Script language in order to define the new scripting language used for P2TR script path spends. Tapscript was introduced by BIP-0342, implemented with the Taproot soft fork.

To implement the various changes associated with Taproot, it proved necessary to revisit the Script language. This is the purpose of Tapscript, which disables or modifies certain opcodes and adds new ones.
