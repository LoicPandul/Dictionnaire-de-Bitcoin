Network of relay servers (nodes) that anonymizes the origin of TCP connections on the internet. It works by encapsulating data in several layers of encryption. Each relay node peels off one layer to reveal the address of the next node, until the final destination is reached. The Tor network provides anonymity by preventing intermediate nodes from knowing both the origin and the destination of the data, which makes it very difficult for an observer to trace the user's activity. The Tor network can be used with Bitcoin to avoid associating an IP address with a Bitcoin node, and thereby avoid leaking some personal information.

*"Tor" stands for "The Onion Router". It is important to distinguish Tor the network from Tor Browser, a web browser based on Firefox that is specifically designed to use the Tor network.*
