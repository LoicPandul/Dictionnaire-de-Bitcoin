Unique identifier associated with each Bitcoin transaction. It is generated by computing the `SHA256d` hash of the transaction data. The TXID is a reference for finding a specific transaction within the blockchain. It is also used to refer to a UTXO, through an outpoint, which is essentially the concatenation of the TXID of a previous transaction and the index of the designated output (also called “vout”). For post-SegWit transactions, the TXID no longer includes the transaction witness, which removes malleability.
