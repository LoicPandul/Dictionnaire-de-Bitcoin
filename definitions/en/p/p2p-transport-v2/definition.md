New version of the Bitcoin P2P transport protocol that incorporates opportunistic encryption to improve the privacy and security of communications between nodes. This improvement aims to resolve several problems of the base version of the P2P protocol, notably by making the exchanged data indistinguishable to a passive observer (such as an internet service provider), thereby reducing the risks of censorship and of attacks that detect specific patterns in data packets.

The encryption in place does not include authentication, so as not to add needless complexity and not to compromise the fact that connecting to the network remains permissionless. This new P2P transport protocol nonetheless offers better security against passive attacks and makes active attacks (notably MITM attacks) considerably more costly and detectable. The introduction of a pseudorandom data stream complicates the task of attackers who wish to censor or manipulate communications.

Specified by BIP-0324, the P2P v2 transport was included as an option (disabled by default) in version 26.0 of Bitcoin Core, released in December 2023. It has been enabled by default since Bitcoin Core 27.0. It can still be disabled with the `v2transport=0` option in the configuration file.
