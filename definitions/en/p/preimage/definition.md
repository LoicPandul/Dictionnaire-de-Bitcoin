In mathematics, the set of all $x$ such that $f(x) = y$, for a function $f$ and an element $y$. It is the operation of inverting the function: going back from the output to the input.

In cryptography, this concept underlies the security of hash functions: preimage resistance requires that, given a hash $h$, it be computationally infeasible to find $m$ such that $H(m) = h$. The function $H$ acts as a one-way function: easy to compute, nearly impossible to invert.

In Bitcoin, the term comes up whenever hash functions are discussed, but it takes on a more specific meaning on Lightning, where the preimage is the random secret value whose hash serves as the lock for payments. When a recipient issues an invoice, they generate a 32-byte preimage, compute its SHA-256 hash (the payment hash), and include it in the invoice. The HTLCs set up along the payment route are locked by this hash. The payment is finalized only when the recipient reveals the preimage to the node preceding it on the route. That node can then unlock the corresponding HTLC, and the preimage propagates back along the route, letting each intermediate node claim its funds. Revealing the preimage is thus the cryptographic proof that the payment was received.
