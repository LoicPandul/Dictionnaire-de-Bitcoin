In wallet software that uses Miniscript, such as Liana, the primary path is the set of keys that allow immediate spending of funds, without any time condition. This path is always available and is used for day-to-day management of the bitcoin, without any waiting (timelock), unlike recovery paths. Take a script that includes 2 distinct keys: key A, which authorizes immediate spending of the bitcoin, and key B, which can spend it after a delay defined by a timelock of 52,560 blocks. In this example, key A comes from the primary path, while key B comes from the recovery path.
