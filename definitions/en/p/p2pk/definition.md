Acronym for *Pay to Public Key*. Standard script template used on Bitcoin to set spending conditions on a UTXO. It locks bitcoin directly to a public key, rather than to an address.
Technically, the P2PK script contains a public key and an instruction that requires a matching digital signature to unlock the funds. When the owner wants to spend the bitcoin, a signature produced with the associated private key must be provided. This signature is verified with the ECDSA (*Elliptic Curve Digital Signature Algorithm*) algorithm. P2PK was often used in the early versions of Bitcoin, notably by Satoshi Nakamoto. It is hardly used anymore today.
