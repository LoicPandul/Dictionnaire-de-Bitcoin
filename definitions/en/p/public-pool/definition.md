Open-source solo mining pool for Bitcoin, created by Benjamin Wilson. Unlike classic pools, which pool computing power and share rewards, Public Pool works on the principle of solo mining: each miner individually tries to find a block and, if successful, keeps the entire reward.

The platform charges no fees on its hosted instance. It provides a block template to miners, which saves them from having to run their own full node.

Public Pool is part of the Open Source Miners United ecosystem and integrates natively with projects such as NerdMiner and Bitaxe.
