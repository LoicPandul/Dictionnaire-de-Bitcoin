Specialized implementation of a Lightning node (Eclair), designed to send and receive payments from a server. Phoenixd uses the same software as the Phoenix mobile wallet and node, but unlike it, which is intended exclusively for smartphones, phoenixd can run on a server as a daemon. Instead of a graphical user interface (GUI), it comes with an HTTP API and handles channel and liquidity management automatically. Phoenixd is a project developed and maintained by the French company ACINQ.
