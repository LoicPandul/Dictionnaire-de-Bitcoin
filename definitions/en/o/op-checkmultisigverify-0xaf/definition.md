Combines an `OP_CHECKMULTISIG` and an `OP_VERIFY`. It takes several signatures and public keys to verify that `M` of `N` signatures are valid, as `OP_CHECKMULTISIG` does. Then, like `OP_VERIFY`, if the verification fails, the script stops immediately with an error. If the verification succeeds, the script continues without pushing a value onto the stack. This opcode was removed in Tapscript.
