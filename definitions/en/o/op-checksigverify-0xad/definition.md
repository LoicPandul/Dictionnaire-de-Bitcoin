Performs the same operation as `OP_CHECKSIG`, but if the signature verification fails, the script stops immediately with an error and the transaction is therefore invalid. If the verification succeeds, the script continues without pushing a value `1` (true) onto the stack. In short, `OP_CHECKSIGVERIFY` performs the `OP_CHECKSIG` operation followed by `OP_VERIFY`. This opcode was modified in Tapscript to verify Schnorr signatures.
