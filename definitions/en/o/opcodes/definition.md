Set of commands used in Bitcoin's Script system. Script is a stack-based programming language used to set spending conditions and thereby, indirectly, to secure bitcoin. The instructions used in the Script language are called "opcodes". They are logical operators and commands for manipulating stacks. These specific instructions are executed by the network's nodes when validating a transaction. Script is not Turing complete. It can be categorized as a mid-level language (almost low-level) inspired by Forth.
