Marks a script as invalid, which makes the output containing it provably unspendable. Bitcoin Core therefore never adds this output to its UTXO set. `OP_RETURN` is often used to embed arbitrary data in the blockchain. By default, Bitcoin Core's `datacarrier` relay rule limited this data to 80 bytes; since Bitcoin Core 30.0, the default limit of `-datacarriersize` has been raised to 100,000 vB.
