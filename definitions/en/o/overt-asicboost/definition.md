Open and transparent version of AsicBoost. AsicBoost is an algorithmic optimization technique used in Bitcoin mining. Miners using the Overt version manipulate the `nVersion` field of the candidate block and use this modification as an additional nonce. Each `nVersion` value changes the first SHA256 chunk of the header and therefore yields a different intermediate result (midstate), while the second chunk, which contains the `Nonce`, stays the same. The expansion of this second chunk, computed only once for each `Nonce` value, is reused with all these midstates, which reduces the computation required. This version is publicly detectable and does not conceal its modifications from the rest of the network, unlike the Covert version of AsicBoost.
