Synonym sometimes used for address reuse. Output linking refers to the practice of using the same receiving address to lock several UTXOs, sometimes across several different transactions. Bitcoin is generally locked with a cryptographic key pair that corresponds to a single address. Since the blockchain is public, it is easy to look up which addresses are associated with how much bitcoin. When the same address is reused for several payments, one might assume that all the associated UTXOs belong to the same entity. Address reuse therefore poses a problem for the user's privacy. It makes it possible to draw deterministic links between several transactions and several UTXOs, and to keep funds traceable on-chain.
