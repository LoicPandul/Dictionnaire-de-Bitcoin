Node to which a Bitcoin node actively establishes a connection. By default, Bitcoin Core opens 8 full outbound connections, which relay blocks and transactions. To these are added 2 block-relay-only connections, which relay only blocks, and, from time to time, a short-lived feeler connection used to check that an address responds. These connections are favored and considered more reliable than inbound peers, because they are chosen by the node. Inbound and outbound peers share the same type of information. The main difference between inbound and outbound peers lies not in the type of information exchanged, but in how these connections are established.
