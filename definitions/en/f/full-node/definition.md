Computer that runs a Bitcoin protocol client, and that downloads and validates the entire blockchain, that is the complete transaction history since the genesis block, and stores it in full, unless it is pruned: a pruned node is also a full node, but keeps only the most recent blocks. A full node independently validates all transactions and blocks according to Bitcoin's consensus rules. It is therefore this type of node that provides the highest level of verification for its user, and that reduces as much as possible the need to trust a third party. A full node requires more storage, computing power, RAM, and bandwidth than a light client (SPV).
