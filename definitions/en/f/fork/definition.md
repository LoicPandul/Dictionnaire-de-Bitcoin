The term "fork" has several meanings in the context of Bitcoin. It refers either to a split of the node network into several separate groups, resulting in the creation of several different blockchains, or to a change to the protocol rules, or even both at once. To simplify, there are 4 main categories of forks:
* Natural fork: occurs when two blocks discovered at the same time at the same height temporarily compete. This fork can extend over several blocks. This type of fork resolves naturally when one of the chains accumulates more work than the other, leading to a reorganization. The reorganization shows up as all nodes agreeing again on a single blockchain;
* Code fork: consists of creating an entirely new cryptocurrency from Bitcoin's source code, launching a new blockchain from the genesis block;
* Hard fork: a change to the Bitcoin protocol that is incompatible with earlier versions, by removing rules or relaxing existing ones. It results in the creation of two distinct, incompatible chains if not all nodes are updated. The network then splits in two: those that adopt the new rules and those that keep the old ones;
* Soft fork: involves backward-compatible changes that add rules or make existing ones more restrictive, without splitting the network. Nodes that do not adopt the new rules can keep following the same chain as the others, provided that the majority of the network's hash power supports the updated chain.
