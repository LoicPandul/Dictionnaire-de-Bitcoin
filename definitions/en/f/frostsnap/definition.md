Bitcoin security system based on the FROST protocol (Flexible Round-Optimized Schnorr Threshold Signatures). Unlike classic multisig built with Bitcoin Script, FROST produces a single on-chain Schnorr signature, indistinguishable from a single-signature transaction, which improves privacy and reduces transaction fees. The Frostsnap team, which includes Nick Farrow and Lloyd Fournier, develops dedicated hardware devices that connect in a chain over USB-C. The system makes it possible to add or remove signers after key generation without changing the public address. The hardware and software are fully open source under the MIT license.
