Hardware wallet made by Blockstream, designed to secure Bitcoin private keys and compatible with the Liquid Network. Jade stands out for an original security model: instead of using a secure element chip, it relies on a “virtual secure element” model in which the private key is encrypted and can be decrypted only by combining a secret stored on the device with a secret held by a Blockstream server (or a personal server).

Jade firmware is fully open source. The devices have a camera for air-gapped use through QR codes, and they work with Blockstream Green, Sparrow Wallet, and other compatible software. The Jade family includes two hardware wallets: the original Blockstream Jade, available preassembled or as a DIY kit, and the Blockstream Jade Plus, the newest and more premium model, with a large color screen and a polished user experience.
