Acronym for *Uniform Resource Identifier*. Standardized string format used to identify a resource on the internet. A URI can be either a URL (Uniform Resource Locator), which provides a way to access a resource by giving its location on a computer network, or a URN (Uniform Resource Name), which names the resource without indicating how to locate it. URIs are important to how the World Wide Web works, because they provide access to resources such as web pages, documents, and services.

In the context of Bitcoin, a URI is used specifically to facilitate transactions. It can encode a receiving address, along with other transaction parameters such as the amount, in a standardized format according to BIP-0021. This simplifies the payment process by letting users click a link or scan a QR code, which automatically feeds the necessary information into their Bitcoin wallet application.
