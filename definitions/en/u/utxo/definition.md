Acronym for *Unspent Transaction Output*. Transaction output that has not yet been spent, that is, used as an input for a new transaction. UTXOs represent the portion of bitcoin that a user owns and that is currently available to spend. Each UTXO is associated with a specific locking script (`scriptPubKey`), which defines the conditions required to spend the bitcoin. Bitcoin transactions consume these UTXOs as inputs and create new UTXOs as outputs. The UTXO model is fundamental to Bitcoin, because it makes it easy to verify that transactions do not try to spend bitcoin that does not exist or has already been spent.
