Files in Bitcoin Core dedicated to indexing all the transactions in the blockchain. This indexing lets a node quickly look up detailed information about a transaction by its transaction ID (txid), without having to scan the entire blockchain. Creating these index files is an option that is not enabled by default in Bitcoin Core. Without this index, the node can only look up by identifier the transactions in its mempool, unless the hash of the block containing the transaction is provided. To enable indexing of all transactions, the `txindex=1` parameter must be set in the `bitcoin.conf` file. This option is particularly useful for applications and services that frequently search the history of Bitcoin transactions.
