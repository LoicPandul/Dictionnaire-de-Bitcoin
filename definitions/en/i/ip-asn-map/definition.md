File used in Bitcoin Core to store the ASMAP, which improves the bucketing (that is, the grouping) of IP addresses based on autonomous system numbers (ASNs). Rather than grouping outbound connections by IP network prefix (`/16`), this file diversifies connections by providing a map from IP addresses to ASNs, which are unique identifiers for each network on the Internet. The idea is to improve the security and topology of the Bitcoin network by diversifying connections to guard against certain attacks (notably the Erebus attack).
