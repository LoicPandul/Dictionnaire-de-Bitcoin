Sequential number assigned to a child key generated from a parent key, in the context of an HD wallet. This index is used together with the parent key and the parent chain code to deterministically derive unique child keys. It enables a structured organization and the reproducible generation of multiple sibling child key pairs from the same parent key. It is a 32-bit integer used in the `HMAC-SHA512` derivation function. This number therefore distinguishes sibling child keys within an HD wallet.
