Script that specifies the conditions under which bitcoin can be spent in P2WSH or P2SH-P2WSH UTXOs. Typically, a `witnessScript` sets the conditions of a multisig wallet under the SegWit standard. In these script standards, the `scriptPubKey` of the UTXO (the output) contains a hash of the `witnessScript`. To use this UTXO as an input in a new transaction, the holder must reveal the original `witnessScript`, in order to prove that it matches the hash in the `scriptPubKey`. The `witnessScript` must then be included in the `scriptWitness` of the transaction, which also contains the elements needed to validate the script, such as signatures. The `witnessScript` is therefore the SegWit equivalent of the `redeemScript` in a P2SH transaction, with the difference that it is placed in the witness of the transaction rather than in the `scriptSig`.

*Note that the `witnessScript` must not be confused with the `scriptWitness`. While the `witnessScript` defines the spending conditions of a P2WSH or P2SH-P2WSH UTXO and is a script in its own right, the `scriptWitness` holds the witness data of any SegWit input.*
