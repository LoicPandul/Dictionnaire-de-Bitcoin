Software tool designed specifically to secure and manage a user's private keys. If the wallet is stored and managed on a software tool itself installed on a general-purpose machine, it is called a "hot wallet." In contrast, if it is stored in software itself installed on a hardware device dedicated solely to this task and not connected to the internet, it is called a "cold wallet." The wallet notably makes it possible to use the private keys to sign transactions, and thus to meet the conditions for spending bitcoin.
