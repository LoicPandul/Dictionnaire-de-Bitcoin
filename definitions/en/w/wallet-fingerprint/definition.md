Set of distinctive characteristics observable in the transactions made by a single Bitcoin wallet. These characteristics can include similarities in the use of script types, address reuse, the ordering of UTXOs, the position of change outputs, Replace-by-Fee (RBF) signaling, the version number, the `nSequence` field, and the `nLockTime` field.

Wallet fingerprints are used by analysts to trace the activity of a particular entity on the blockchain by identifying recurring patterns in its transactions. For example, a user who systematically sends change to P2TR addresses (`bc1p…`) creates a characteristic fingerprint that can be used to follow future transactions.

As LaurentMT explains in Space Kek #19 (a French-language podcast), the usefulness of wallet fingerprints in chain analysis grows significantly over time. The growing number of script types and the increasingly staggered adoption of these new features by wallet software accentuate the differences. It is even sometimes possible to identify exactly which software the traced entity uses. The study of a wallet's fingerprint is therefore particularly relevant for recent transactions, more so than for those initiated in the early 2010s.
