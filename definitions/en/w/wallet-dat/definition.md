File in Bitcoin Core that stores information about the user's wallet, such as private keys and transactions made. The `wallet.dat` file can be encrypted by the user to secure the funds, but it is not encrypted by default. Since Bitcoin Core 0.16.0, a new data directory places wallets in its `wallets/` subfolder, and each named wallet has its own folder there (`wallets/<name>/wallet.dat`). Since Bitcoin Core 0.21.0, descriptor wallets store this file as an SQLite database, whereas legacy wallets use Berkeley DB, a format that Bitcoin Core 30.0 no longer loads.
