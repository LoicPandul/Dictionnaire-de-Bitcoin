Protocol that embeds formatted image data directly in the Bitcoin blockchain through bare multisig (P2MS) transactions. Stamps encodes the binary content of an image in base64 and places it in the keys of a 1-of-3 P2MS. One key is real and is used to spend the funds, while the other two are fake keys (the associated private key is not known) that store the data. By encoding data directly as public keys rather than using `OP_RETURN` outputs, images stored with the Stamps protocol are particularly burdensome for nodes. In particular, this method creates multiple UTXOs, which increases the size of the UTXO set and causes problems for full nodes.
