Open-source layer 2 protocol built on Bitcoin and developed by Lightspark, designed to allow instant, very low-cost transactions while preserving users' self-custody. Spark relies mainly on statechain technology: rather than moving bitcoin on-chain at each transfer, the protocol changes the spending authorization shared between the user and a group of operators called the Spark Entity (SE). The SE is made up of several Spark Operators (SO) that jointly take part in a shared signing protocol. A single honest operator is enough to prevent any collusion with a former owner.

Unlike the Lightning Network, which requires managing payment channels, Spark transfers UTXO ownership off-chain without liquidity constraints or channel management. The protocol is natively compatible with Lightning: users can send and receive Lightning payments without running a node. Spark also supports issuing tokens (BTKN) and stablecoins directly on Bitcoin. The user can withdraw funds to the base layer at any time, unilaterally, without the SE's permission. Transfers between Spark wallets settle in under a second, with no fees.
