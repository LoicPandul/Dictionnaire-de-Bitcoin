Low-level programming language designed by Russell O'Connor at Blockstream to express contracts on blockchains based on the UTXO model. Presented in a white paper in 2017, Simplicity differs from languages like Solidity (Ethereum) in that it is not Turing-complete: it can express any finite function, but forbids unbounded loops and global state. This restriction guarantees that every execution terminates and that the resource cost of a program is known before it runs. The language was deployed on Liquid in July 2025, where it gives asset issuers the ability to create verifiable contracts. Unlike Miniscript, which is limited to signatures, timelocks, and hash preimages within Script, Simplicity can express arbitrary functions, but it requires a consensus environment separate from Bitcoin's.
