In the RGB protocol, a state extension is a contract operation that initiates an update to a contract's state by redeeming previously declared valencies. This procedure exploits a public right written into the contract to trigger a change, which becomes effective only once it has been closed by a state transition. The latter incorporates the final update of the contract's state. This mechanism was removed from the protocol with RGB v0.12 (2025), which eliminates valencies, redemptions, and extension graphs.
