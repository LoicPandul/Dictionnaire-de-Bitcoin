Open-source project for a DIY (build-it-yourself) hardware wallet based on a Raspberry Pi Zero, a screen, and a camera. SeedSigner is designed to generate and handle Bitcoin private keys in an air-gapped way and communicates exclusively through QR codes.

Its main characteristic is its "stateless" nature: the device keeps no data in memory between uses, which means the mnemonic phrase must be entered each time, by scanning a QR code. This approach eliminates the risk of keys being extracted from the device in the event of physical access.

The software is fully open source and the build cost is fairly low, which makes it an accessible solution for signing transactions or managing a multisig. Since it can be assembled from general-purpose computer hardware, it is also an accessible solution for people living under an authoritarian regime.
