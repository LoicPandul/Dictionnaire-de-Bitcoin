Data structure that extends the properties of a classic Merkle tree by making it possible to produce proofs of non-inclusion in addition to proofs of inclusion. In an SMT, each element is placed at a position in the tree determined by the SHA-256 hash of its data: each bit of the hash indicates a left or right traversal of the binary tree. Since most leaves remain empty, the tree is called “sparse”, which allows efficient generation and updating by pruning empty branches. SMTs are used in the Taproot Assets protocol to manage asset transfers and prove that a given asset has not been spent twice.
