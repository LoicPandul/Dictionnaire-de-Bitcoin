Element in the inputs of SegWit transactions that contains the signatures and public keys needed to unlock the bitcoin sent in the transaction. Similar to the `scriptSig` of Legacy transactions, the `scriptWitness` is not placed in the same location, however. It is this part, called the "witness", that is moved into a separate data structure to solve the problem of transaction malleability. Each SegWit input has its own `scriptWitness`, and all the `scriptWitness` elements together form the transaction's `Witness` field.

*Not to be confused with the `witnessScript`. While the `scriptWitness` contains the witness data of any SegWit input, the `witnessScript` defines the spending conditions of a P2WSH or P2SH-P2WSH UTXO and is a script in its own right, much like the `redeemScript` for a P2SH output.*
