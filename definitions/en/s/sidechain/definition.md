Blockchain designed to run in parallel with Bitcoin's main blockchain. The two chains are connected by a two-way peg, which ensures that the asset circulating on the sidechain keeps the same value as bitcoin on the main chain. The sidechain has its own consensus mechanism, which can be independent or can rely partly on that of the main chain. It generally allows features that are not available directly on the main chain to be used, or offers improved features, such as more flexibility in development, faster and/or more private transactions, or higher transaction capacity. To do so, the sidechain makes trade-offs compared with the main chain.

The sidechain concept was first presented in 2014 by Adam Back, Matt Corallo, Luke Dashjr, Mark Friedenbach, Gregory Maxwell, Andrew Miller, Andrew Poelstra, Jorge Timón, and Pieter Wuille. In 2026, the best-known sidechains on Bitcoin are Liquid and RSK (Rootstock). However, they remain little used compared with other layer 2 solutions with a different model, such as the Lightning Network.
