Variant of the `SIGHASH_ANYPREVOUT` modifier sighash flag in Bitcoin, introduced in BIP-0118. This sighash flag works like `SIGHASH_ANYPREVOUT`, but in addition to not committing to the specific UTXO being spent, the signature commits to neither the script (scriptCode/tapscript) nor the amount of the input. This allows the same signature to be reused to spend any UTXO that uses the same BIP-0118 public key, whatever the associated script or amount.
