Static list of public Bitcoin nodes, built directly into the Bitcoin Core source code (`bitcoin/src/chainparamsseeds.h`). This list serves as connection points for new Bitcoin nodes joining the network, but it is used only if the node still has no address for one of the networks it uses after 60 seconds, for example because the DNS seeds did not respond. In that case, the new Bitcoin node connects to these seed nodes to establish a first connection to the network and request the IP addresses of other nodes. The ultimate goal is to acquire the information needed to perform the initial block download (IBD) and synchronize with the chain that has the most accumulated work. The seed node list contains about 2,000 nodes (2,057 in Bitcoin Core 32.1), identified according to the standard set by BIP-0155. Seed nodes are thus the third method a Bitcoin node uses to connect to the network, after the possible use of the `peers.dat` file, created by the node itself, and the querying of DNS seeds.

*Seed nodes should not be confused with “DNS seeds”, which are the second way of establishing connections.*
