Open-source software suite for managing Bitcoin wallets, with a particular focus on multisig setups. Specter Desktop is a desktop application that interfaces directly with a personal Bitcoin Core node to create and manage singlesig and multisig wallets, compatible with most hardware wallets on the market (Trezor, Ledger, Coldcard, etc.). The project also includes Specter DIY, open-source firmware for building one's own signing device from standard electronic components.
