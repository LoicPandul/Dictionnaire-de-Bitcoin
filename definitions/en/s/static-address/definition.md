In the context of Silent Payments, a unique identifier that makes it possible to receive payments without address reuse, without interaction, and without any visible on-chain link between the payments and the static address. This technique removes the need to generate a fresh receiving address for each transaction, which avoids the usual interaction in Bitcoin where the recipient must give the payer a new address. It is roughly the equivalent of the reusable payment code in BIP-0047.

This address is made of two public keys: $B_{scan}$ for scanning and $B_{spend}$ for spending, concatenated to form the static address $B\ =\ B_{scan}\ \Vert\ B_{spend}$. The recipient publishes this address, which lets senders derive unique payment addresses without any further interaction with the recipient. To handle several distinct sources of payments, a label can be added to $B_{spend}$, creating several labeled static addresses (from $B_1$, $B_2$, etc.). This segregates payments while using a single base address, which reduces the workload of scanning the blockchain. However, all of an entity's static addresses can easily be linked because they share $B_{scan}$.
