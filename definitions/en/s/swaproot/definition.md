On-chain deposit protocol into a Lightning channel designed by ACINQ and deployed in the Phoenix wallet in February 2024. Swaproot is an evolution of the swap-in potentiam protocol that takes advantage of Taproot and MuSig2 to make swap-in transactions cheaper, more private, and compatible with address rotation.

The earlier protocol used a pay-to-script construction of the form “user key + server key OR user key + delay”. This structure was identifiable on-chain and required a static address. Swaproot replaces the cooperative path with a Taproot key path spend: the user's and the server's keys are aggregated through MuSig2 into a single public key. When the two parties cooperate to perform a splice-in, the transaction is indistinguishable from an ordinary P2TR payment. The refund path (user key + delay) is relegated to the script path, invisible except in the case of a unilateral recovery.
