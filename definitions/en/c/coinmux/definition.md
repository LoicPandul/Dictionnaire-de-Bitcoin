Coinjoin implementation developed in 2014. Coinmux is a decentralized, trustless bitcoin mixing protocol that requires neither trust between participants nor the intervention of a central party. The software pools the bitcoin of several users into a single transaction, where every output has the same amount, which breaks the links between inputs and outputs. Coinmux's protocol ensures that users keep control of their funds throughout the process, by having transactions signed only when the inputs and outputs match exactly what was agreed. Today, this protocol is no longer used.
