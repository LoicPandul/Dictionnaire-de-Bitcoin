Hidden version of AsicBoost. AsicBoost is an algorithmic optimization method for Bitcoin mining. In its covert version, miners manipulate the Merkle tree rather than the nonce, which reduces the computation needed for each SHA256 hash by keeping some data unchanged between hashing attempts. Unlike the overt version of AsicBoost, the covert version conceals the use of AsicBoost during the mining process. However, since the introduction of SegWit and its second Merkle tree, this method is no longer effective, because the number of calculations required to use it has become too high compared with standard mining.
