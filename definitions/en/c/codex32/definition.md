Scheme for encoding and backing up BIP-0032 seeds on paper, specified in BIP-0093. Codex32 stands out from existing alternatives by allowing the integrity of a backup to be verified by hand, without any electronic device.

The system relies on Shamir's secret sharing: the seed can be split into several shares, of which only a configurable subset (the quorum) is needed to reconstruct the secret. Each share is encoded as a Bech32 string that includes a checksum. This checksum is what makes Codex32 unique: it can be computed and verified entirely by hand using lookup tables or rotating paper templates called “volvelles”. The operation remains laborious, but it guarantees that a user can audit their backups in a fully offline environment with no digital component.

Codex32 supports 128-bit and 256-bit seeds. It is an alternative to SatoshiLabs' SLIP39 scheme, which also offers Shamir's secret sharing but requires an electronic device for verification. Core Lightning added support for Codex32 for seed backup and restoration in 2023.
