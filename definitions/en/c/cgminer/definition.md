Open-source mining software originally developed for CPU and GPU. CGminer lets users manage and optimize their mining operations, with features such as multithreading, management of multiple pools, and real-time performance monitoring. Its GitHub repository is archived and its last commit dates from 2018. In Braiins OS, a firmware for ASICs, BOSminer, mining software written from scratch in Rust by Braiins, now plays the role of CGminer.
