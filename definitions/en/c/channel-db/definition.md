Database used by LND to store the complete state of all of a node's Lightning channels. This file is located in the `.lnd/data/graph/mainnet` directory and contains the list of open channels, peer identifiers, the latest commitment transactions for each channel, and the information needed to punish a peer who attempts to broadcast an old state.

The `channel.db` file changes constantly: every payment, every routing event, and every channel opening or closing alters its content. This is why it is not a reliable backup medium in the conventional sense. Restoring an outdated version of `channel.db` exposes the operator to the penalty mechanism of the Lightning protocol: peers may consider that an old state is being broadcast and recover all the funds in the channel. The only safe use of `channel.db` for a restoration is direct recovery from a machine that has just crashed, which guarantees that the state is the most recent. For a reliable backup, LND instead offers the SCB (Static Channel Backup) mechanism.
