Versatile programming language, evolved from C, known for its power and flexibility. Used for complex software development, it supports object-oriented programming and offers rich features for managing memory and system resources.

Bitcoin Core, the majority implementation of the Bitcoin protocol, is written in C++. This is a legacy of Satoshi's very first client, which was also written in this programming language. To guarantee strictly consistent behavior of nodes across the network, notably to avoid forks, the decision was made not to change language since 2009.
