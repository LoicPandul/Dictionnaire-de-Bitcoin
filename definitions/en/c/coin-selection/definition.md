Process by which Bitcoin wallet software chooses which UTXOs to use as inputs to satisfy the outputs of a transaction. The coin selection method matters because it affects the cost of a transaction and the user's privacy. It often aims to minimize the number of inputs used, to reduce the transaction size and the associated fees, while trying to preserve privacy by avoiding the merging of coins from different sources (CIOH). Several methods exist for coin selection, such as the knapsack solver or branch-and-bound. When the user performs coin selection manually, it is known as coin control.
