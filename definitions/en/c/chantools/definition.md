Command-line tool developed by Lightning Labs for recovering funds stuck in Lightning channels when the LND node no longer works properly. Chantools steps in during emergencies, when the standard recovery mechanisms (restoring from a Static Channel Backup) fail or are not enough.

The tool offers about thirty commands covering different recovery scenarios: extracting a `channel.backup` file from a corrupted database (`chanbackup`), forcing the publication of a channel's last known state (`forceclose`), sweeping funds after the timelock expires (`sweeptimelock`), recovering funds from force closes initiated by the remote peer (`sweepremoteclosed`), or cooperatively recovering zombie channels (`zombierecovery`). Some commands are also compatible with Core Lightning. Using chantools requires the node's seed, but the seed never leaves the local machine.
