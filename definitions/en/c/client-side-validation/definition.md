Process by which each party (client) verifies a set of privately exchanged data according to the rules of a protocol. In the RGB protocol, this exchanged data is grouped into what are called consignments. Unlike the Bitcoin protocol, which requires all transactions to be published on-chain, RGB stores only commitments publicly (anchored in Bitcoin), while most of the contract information (transitions, attestations, proofs) stays off-chain, shared only between the users concerned.
