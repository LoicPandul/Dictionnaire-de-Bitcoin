Source code management and hosting platform that eases collaboration between developers. GitLab is the main alternative to GitHub. The platform is quite similar, but it can also be self-hosted. As its name suggests, GitLab is built on the Git version control system. The platform therefore tracks code changes, manages versions, and encourages collaboration through tools such as merge requests and issues. Some Bitcoin-related projects have used GitLab, such as Samourai Wallet and Whirlpool, whose self-hosted repository has been offline since the seizure of Samourai's servers in April 2024.
