Source code management and hosting platform that eases collaboration between developers. As its name suggests, GitHub is built on the Git version control system. The platform therefore tracks code changes, manages versions, and encourages collaboration through tools such as pull requests and issues. GitHub has become one of developers' main tools, notably in the Bitcoin community, where many projects, including Bitcoin Core, the main implementation of the protocol, are hosted. In 2018, Microsoft acquired GitHub for $7.5 billion.
