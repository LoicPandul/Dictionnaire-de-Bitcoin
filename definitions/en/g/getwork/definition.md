Legacy Bitcoin mining protocol that appeared in 2010. Getwork let miners receive work data from a full node. It was built on RPC requests that returned block headers to work on in order to find a valid proof of work. Getwork was optimized for GPU mining. It relied on the `getwork` RPC method, added to the Bitcoin code in November 2010 and removed from Bitcoin Core in version 0.10.0. It was popularized by poclbm, m0mchil's open source GPU miner, at a time when a few players kept their mining software private. Getwork was gradually replaced by Stratum, which is more efficient, particularly for ASICs, and uses less bandwidth.
