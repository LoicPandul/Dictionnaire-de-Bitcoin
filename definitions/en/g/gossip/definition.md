Distributed peer-to-peer (P2P) algorithm that spreads information epidemically to all agents in the network. In Bitcoin, Lightning, and other distributed systems, this protocol is used to exchange and synchronize the global state of the nodes in a few cycles. Each node propagates a piece of information to one or more neighbors, chosen randomly or not, and these neighbors in turn propagate it to other neighbors, and so on until a globally synchronized state is reached.

In Lightning, gossip is a communication protocol between nodes for sharing information about the current state and topology of the network. The gossip protocol lets nodes learn the dynamic state of payment channels and of other nodes, which makes it easier to route payments through the network without requiring direct connections between all nodes.
