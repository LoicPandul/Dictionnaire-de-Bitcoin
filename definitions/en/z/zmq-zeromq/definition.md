Asynchronous messaging library used by Bitcoin Core to notify other software in real time of the arrival of new blocks and new transactions. ZMQ works on a publish-subscribe (pub/sub) model: Bitcoin Core publishes events on a socket, and subscribed software (such as LND) receives them instantly without having to poll the node periodically. This interface is essential for Lightning implementations that must react quickly to transaction confirmations, notably to detect channel closures and publish justice transactions.
