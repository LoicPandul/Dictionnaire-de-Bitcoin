Open-source backend server built on top of Bitcoin Core, oriented toward privacy and self-reliance. Initially developed by the Samourai Wallet team, the Dojo project is now maintained by the community. Dojo acts as a gateway between a Bitcoin wallet (such as Ashigaru) and the Bitcoin network, making it possible to query blockchain data and broadcast transactions through the user's own infrastructure. It includes Bitcoin Core, the Fulcrum indexer, and the BTC-RPC Explorer.
