Cryptographic method by which two parties generate a shared secret over an insecure communication channel. This secret can then be used to encrypt the communication between the two parties. Diffie-Hellman relies on modular arithmetic so that, even if an attacker can observe the exchanges, the attacker cannot derive the shared secret without solving a hard mathematical problem: the discrete logarithm. Bitcoin sometimes uses a variant of DH based on an elliptic curve, called ECDH, notably in static address protocols such as Silent Payments or BIP-0047.
