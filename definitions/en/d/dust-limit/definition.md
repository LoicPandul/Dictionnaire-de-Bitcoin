Threshold in sats below which a network node considers a UTXO to be "dust." This threshold is part of the standardness rules, which each node can change independently. In Bitcoin Core, this limit is determined by a specific fee rate, set by default to 3,000 sats per virtual kilobyte (sats/kvB). The limit aims to restrict the propagation of transactions containing very small amounts of bitcoin. A UTXO qualified as dust is one that is not economically rational to use: spending it would cost more than simply abandoning it. If spending dust is not rational, such spends are likely to be motivated only by external incentives, often malicious. This can notably be a problem if a malicious actor tries to saturate the network with transactions containing tiny amounts, in order to increase the operating load on nodes and potentially keep them from processing other legitimate transactions. To give an analogy (admittedly a somewhat shaky one), it is a bit like someone trying to pay for a €100 grocery basket entirely with 1-cent coins in order to block the other customers at the checkout.
