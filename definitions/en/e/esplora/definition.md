Open-source block explorer developed by Blockstream and publicly accessible at `blockstream.info`. The interface is a single-page web application (SPA) that consumes the HTTP API provided by esplora-electrs, a modified version of Electrs in Rust that indexes the blockchain from a Bitcoin Core node. The tool also supports Liquid and Elements-based chains, with handling of confidential transactions and peg-in/peg-out operations.
