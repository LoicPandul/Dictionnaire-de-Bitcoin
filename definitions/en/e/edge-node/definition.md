Specialized routing node that acts as an intermediary between Taproot Assets wallets and the standard Lightning Network. An edge node maintains public Bitcoin channels to the Lightning Network and unannounced Taproot Assets channels with its clients. Its main function is to convert Taproot Assets into BTC (and vice versa) when routing payments, via standard hashed time-locked contracts (HTLCs).

In practice, a wallet holding a Taproot asset (for example a dollar stablecoin) can pay any BOLT-11/12 Lightning invoice: the edge node receives the asset from the client, performs the conversion, and routes the payment in BTC over the network. Conversely, an incoming Lightning payment in BTC can be converted into a Taproot asset before being delivered to the client. The edge node provides quotes for each conversion and collects routing fees. It never takes custody of the client's funds: the exchanges are atomic thanks to HTLCs.
