Protocol developed by Lightning Labs for connecting remotely to a Lightning node through a proxy server, without exposing the node directly to the internet. LNC establishes an end-to-end encrypted connection between the client (for example Lightning Terminal in a browser) and the node, authenticating with a pairing phrase. The protocol removes the need to set up a VPN, open ports, or manage TLS certificates, which greatly simplifies remote access to a personal node hosted behind a NAT or a firewall.
