Open-source application that sits on top of any Lightning funding source (LND, Core Lightning, LNbits itself, etc.) and lets users create isolated virtual wallets, each with its own API key. The main benefit is that the total balance of the underlying node is never exposed: each wallet sees and can spend only the funds allocated to it, which makes it possible to delegate access to third-party applications without risk.

LNbits uses a modular architecture in which the core stays minimal and all additional features come from optional extensions developed by the community: point of sale, payment links, paywalls, NIP-05 for Nostr, Bolt Cards, payment terminals, crowdfunding, and more. Developers can create and share their own extensions. LNbits natively supports LNURL and Nostr, provides a complete REST API, and is accessible from a web browser.
