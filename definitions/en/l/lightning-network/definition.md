Second-layer protocol built on top of the Bitcoin protocol, designed to enable fast, low-cost transactions. It allows payment channels to be created between participants, within which transactions can be made almost instantly and with minimal fees, without recording each individual transaction on the blockchain. Channels can stay open almost indefinitely, and only require on-chain transactions when they are opened and closed. The Lightning Network aims to improve Bitcoin's scalability and make it usable for low-value payments.
