Open-source Bitcoin wallet software developed by Wizardsardine, a company founded by Kevin Loaec and Antoine Poinsot. Liana stands out for its use of Miniscript to enable advanced, highly customizable security setups, notably recovery mechanisms based on timelocks. For example, a user can define a primary key for everyday spending, then one or more recovery keys that become active only after a set period of inactivity. This model makes it possible to set up inheritance plans or automatic backup mechanisms without a trusted third party. Liana is compatible with hardware wallets that support Miniscript.
