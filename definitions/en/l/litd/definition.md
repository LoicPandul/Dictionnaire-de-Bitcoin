Daemon that bundles several Lightning Labs tools into a single process: LND, Loop, Pool, Faraday, and Taproot Assets. By running litd, a node operator gets access to all of these services without installing and configuring them separately. The daemon also provides the Lightning Terminal web interface for administering the node, and exposes the Lightning Node Connect (LNC) protocol, which allows secure remote access from a web browser without complex network setup such as a VPN or port forwarding.
