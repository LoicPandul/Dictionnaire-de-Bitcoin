File used in Bitcoin Core to lock the data directory. It is created when `bitcoind` or Bitcoin-qt starts, to prevent several instances of the software from accessing the same data directory at once. The goal is to prevent conflicts and data corruption. The locking relies on an operating system lock mechanism applied to the `.lock` file. The file itself stays on disk permanently, but the lock is released automatically by the operating system when the process ends, including after an unexpected shutdown.
