Communication protocol that specifies a set of features designed to simplify interactions between Lightning nodes and clients, as well as third-party applications. The protocol is based on HTTP and makes it possible to create links for various operations, such as a payment request, a withdrawal request, or other features that improve the user experience. Each LNURL is a URL encoded in bech32 with the prefix `lnurl` which, once scanned, triggers a series of automatic actions in the Lightning wallet.

For example, the LNURL-withdraw feature (LUD-03) lets a user withdraw funds from a service by scanning a QR code, without having to generate an invoice manually. Similarly, LNURL-auth (LUD-04) lets a user log in to online services with a private key held in their Lightning wallet instead of a password.
