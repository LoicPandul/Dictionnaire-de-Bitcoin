Lightweight, fast, open-source key-value storage library designed by Google. Bitcoin uses it to store the UTXO set and the block index. This database system was introduced in 2012 as part of the "Ultraprune" pull request, which aimed to replace BerkeleyDB. The change had significant consequences, notably an unintentional hard fork with a major 24-block reorganization on March 12, 2013. The incident is detailed in BIP-0050. Later, the temporary limit on locks introduced in version 0.8.1 expired on May 15, 2013, resulting in a planned hard fork.
