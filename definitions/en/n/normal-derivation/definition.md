Process for generating child keys in HD wallets. Normal derivation uses the parent public key as input to the `HMAC-SHA512` function, which makes it possible to generate child public keys from the parent public key and the parent chain code. The process involves concatenating the parent public key and an index lower than $2^{31}$, followed by applying `HMAC-SHA512` with the parent chain code. The result is split into two parts: the first 256 bits are added to the parent private key to obtain the child private key, while the remaining 256 bits form the child chain code. This method guarantees that the extended public key can be used to derive the child public keys. In a standard derivation, the levels above the account (purpose, coin type, account) use hardened derivation, and normal derivation applies to the levels below the account (the change chain and the address index). In derivation path notations, a normal derivation is identified when there is just the index with no apostrophe `'`.
