Protocol defined by NIP-47 that makes it possible to control a Lightning wallet remotely, using Nostr as the communication layer. NWC establishes an encrypted connection between a Nostr client and a Lightning wallet through Nostr relays, allowing the client to initiate payments, generate invoices, and check the balance without the wallet being built directly into the application. The connection is authenticated by a dedicated Nostr key pair, and the messages exchanged between the client and the wallet are end-to-end encrypted. NWC is particularly useful for separating the user interface from the management of funds: a user can, for example, connect their personal Lightning node to any compatible Nostr client, which makes it easier to send zaps or make Lightning payments on the go, without exposing their private keys to the application.
