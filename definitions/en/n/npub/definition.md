Encoding format of the Nostr public key in Bech32, defined by NIP-19. The `npub` prefix identifies a Nostr public key. The raw public key is a 32-byte number on the secp256k1 curve, derived from its private key. The `npub` encoding adds a human-readable prefix (`npub1...`) and a checksum to detect typing errors, and uses an alphabet that excludes ambiguous characters. The `npub` is the public identifier of a Nostr user: it can be shared freely and lets anyone find the associated profile and posts. Unlike the `nsec`, it does not compromise the security of the account if disclosed.
