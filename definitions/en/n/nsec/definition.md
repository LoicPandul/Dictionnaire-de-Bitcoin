Bech32 encoding (NIP-19) of a Nostr private key, with the `nsec` prefix. The key is a 32-byte value used as a secret on secp256k1; it makes it possible to produce the Schnorr signatures of Nostr events and thus to prove control of the identity (through the `npub`). Losing the `nsec` means losing control of this identity. The `nsec` must never be shared or entered in an untrusted web client; to reduce exposure, NIP-07 standardizes `window.nostr`, through which an extension can sign events without disclosing the key to the application.
