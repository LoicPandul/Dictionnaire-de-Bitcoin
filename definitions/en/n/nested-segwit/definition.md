Standard script used to wrap native SegWit scripts inside a P2SH script. Nested SegWit scripts were invented at the launch of SegWit to ease its adoption. They make it possible to use this new standard even with services or wallets that are not yet natively compatible with SegWit. It is a kind of transitional script toward the new standard. In 2026, it is therefore no longer very relevant to use this type of wrapped SegWit script, since most wallets have implemented native SegWit.
