Technical specification that defines a feature, a format, or an expected behavior in the Nostr protocol. NIPs play a role analogous to Bitcoin's BIPs: they are community documents that formally describe how clients and relays must implement a given feature. Each NIP has a number and covers a specific aspect of the protocol. With the exception of NIP-01, which describes the base protocol that everyone should implement, NIPs are optional and backward compatible. A NIP can be marked `unrecommended` when it is deprecated or replaced by a more recent specification. The official NIP repository is maintained on GitHub and open to contributions.
